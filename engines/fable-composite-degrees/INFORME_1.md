## STEP 1 — PART A: the colour reduction (A1–A7)

**Standing conventions.** `m = q·r`, `q = p^v`, `p` an odd prime, `p ∤ r`; so `r` is odd. `F := F̄_p`. `n = 2k`, `N = n+2`. `F[G] := F[t_1, …, t_{n+1}]/(t_i^m − 1)`. `I := (ψ̄_J : J ∈ 𝒥)F[G]`. All tensor products are over `F`. «Unit» means an invertible element of the ring in which the statement is made. The inputs taken from the paper are listed at the end of the step; each is quoted with its number.

### (A1) Splitting — PROVED

**Claim.** `F[G] ≅ Π_{c ∈ μ_r^{n+1}} R_c`, `R_c := F[t_1, …, t_{n+1}]/((t_i − c_i)^q : i = 1..n+1) = ⊗_{i=1}^{n+1} F[t_i]/((t_i − c_i)^q)`. For an ideal `I ⊆ F[G]`, `dim_F I = Σ_c dim_F π_c(I)`, where `π_c : F[G] → R_c` is the quotient map and `π_c(I)` is the ideal of `R_c` generated by the images of any generating set of `I`.

*Proof.* (i) One variable. In characteristic `p`, `(t^r − 1)^q = t^{rq} − 1 = t^m − 1` (Frobenius: `(x − y)^{p^v} = x^{p^v} − y^{p^v}`). The polynomial `t^r − 1` is separable, because its derivative `r·t^{r−1}` is coprime to it (`r ≠ 0` in `F`, and `t ∤ t^r − 1`); hence it has `r` distinct roots in `F`, which form the group `μ_r`, and `t^r − 1 = Π_{ζ ∈ μ_r}(t − ζ)`. So `t^m − 1 = Π_ζ (t − ζ)^q`, and the ideals `((t − ζ)^q)`, `ζ ∈ μ_r`, are pairwise comaximal in the principal ideal domain `F[t]`. By the Chinese remainder theorem, `F[t]/(t^m − 1) ≅ Π_{ζ ∈ μ_r} F[t]/((t − ζ)^q)`, the map being the product of the quotient maps.
(ii) Several variables. `F[G] = ⊗_{i=1}^{n+1} F[t_i]/(t_i^m − 1)` (a quotient of a polynomial ring by polynomials in separate variables is the tensor product of the one-variable quotients). Tensor product over a field commutes with finite direct products of algebras: `(A_1 × A_2) ⊗ B ≅ (A_1 ⊗ B) × (A_2 ⊗ B)`, by the map `(a_1, a_2) ⊗ b ↦ (a_1 ⊗ b, a_2 ⊗ b)`, which is an isomorphism of algebras (it is bijective on the bases `{(e_s, 0), (0, e'_s)} ⊗ {f_u}`). Applying (i) in each factor and distributing, `F[G] ≅ Π_{c ∈ μ_r^{n+1}} ⊗_i F[t_i]/((t_i − c_i)^q) = Π_c R_c`, the component maps being the `π_c`.
(iii) Ideals. In a finite product of rings `Π_c R_c` with idempotents `e_c`, every ideal `I` equals `Π_c e_cI = Π_c π_c(I)` (as `x = Σ_c e_c x`), and `π_c(I)` is the ideal of `R_c` generated by the images of the generators of `I` (`π_c` is a surjective ring map). Dimensions add over the product. ∎

### (A2) Which generators survive in `R_c` — PROVED

Fix `c ∈ μ_r^{n+1}` and put `c_0 := (c_1 ⋯ c_{n+1})^{−1}`, so that `Π_{i=0}^{n+1} c_i = 1`. In `R_c`, each `t_i − c_i` is nilpotent, with `(t_i − c_i)^q = 0`.

**(A2.1)** *If `c_i ≠ 1` then `t_i − 1` is a unit of `R_c`; if `c_i = 1` then `t_i − 1` is nilpotent.* Indeed `t_i − 1 = (c_i − 1) + (t_i − c_i)`; if `c_i ≠ 1` this is `(c_i − 1)·(1 + ε)` with `ε := (t_i − c_i)/(c_i − 1)` nilpotent, and `1 + ε` is a unit with inverse `Σ_{s=0}^{q−1} (−ε)^s`. If `c_i = 1` it is `t_i − c_i`.

**(A2.2)** *In `F[u]`: `φ(u) = (u − 1)^{q−1}·Π_{ξ ∈ μ_r, ξ ≠ 1}(u − ξ)^q`.* Indeed `(u − 1)φ(u) = u^m − 1 = Π_{ξ ∈ μ_r}(u − ξ)^q` by (A1)(i), and `F[u]` is a domain, so `u − 1` cancels.

**(A2.3)** *Let `j ≠ k` be in `{1, …, n+1}` and `u := t_jt_k ∈ R_c`. Then `(u − c_jc_k)^q = 0`. If `c_jc_k ≠ 1` then `φ(u) = 0` in `R_c`; if `c_jc_k = 1` then `φ(u) = (unit)·(u − 1)^{q−1}` in `R_c`.* Indeed `t_j^q = (c_j + (t_j − c_j))^q = c_j^q + (t_j − c_j)^q = c_j^q` (Frobenius), and likewise for `t_k`; so `u^q = (c_jc_k)^q` and `(u − c_jc_k)^q = u^q − (c_jc_k)^q = 0`. If `ξ_0 := c_jc_k ≠ 1`, then `ξ_0 ∈ μ_r ∖ {1}` and the factor `(u − ξ_0)^q` of (A2.2) vanishes in `R_c`, so `φ(u) = 0`. If `c_jc_k = 1`, then `u − 1` is nilpotent, and for `ξ ≠ 1` the factor `u − ξ = (1 − ξ) + (u − 1)` is a unit by the argument of (A2.1); so `φ(u) = (unit)·(u − 1)^{q−1}`.

**(A2.4) Compatibility.** Say that `c` is *compatible* with `J = {{0,k_0},{j_1,k_1},…,{j_k,k_k}} ∈ 𝒥` if `c_jc_k = 1` for every pair `{j,k} ∈ J`, the pair `{0,k_0}` included. *Then: (a) `c` is compatible with `J` iff `c_{j_i}c_{k_i} = 1` for `i = 1, …, k`; (b) if `c` is not compatible with `J`, then `π_c(ψ_J) = 0`.* For (a): `1 = Π_{i=0}^{n+1} c_i = c_0c_{k_0}·Π_{i=1}^k c_{j_i}c_{k_i}`, so the `k` conditions imply `c_0c_{k_0} = 1`. For (b): `ψ_J = (t_{k_0} − 1)·Π_{i=1}^k (t_{k_i} − 1)φ(t_{j_i}t_{k_i})` contains, by (a), a factor `φ(t_{j_i}t_{k_i})` with `c_{j_i}c_{k_i} ≠ 1`, which is `0` in `R_c` by (A2.3).

**Consequence.** `π_c(I)` is the ideal of `R_c` generated by `{π_c(ψ_J) : J compatible with c}`, and for a compatible `J`

`π_c(ψ_J) = (unit)·(t_{k_0} − 1)·Π_{i=1}^k (t_{k_i} − 1)(t_{j_i}t_{k_i} − 1)^{q−1}`.   (A2.5)

### (A3) Blocks and the tensor decomposition — PROVED

Fix `c`. Since `r` is odd, `ζ ≠ ζ^{−1}` for every `ζ ∈ μ_r ∖ {1}` (`ζ^2 = 1 = ζ^r` with `r` odd forces `ζ = 1`), so `μ_r ∖ {1}` splits into `(r−1)/2` classes `{ζ, ζ^{−1}}`; fix a set `Z` of representatives. Put

`E := {i ∈ {0, …, n+1} : c_i = 1}`, and for `ζ ∈ Z`: `A_ζ := {i : c_i = ζ}`, `B_ζ := {i : c_i = ζ^{−1}}`.

These sets partition `{0, …, n+1}`. Write `E' := E ∖ {0}`, `A'_ζ := A_ζ ∖ {0}`, `B'_ζ := B_ζ ∖ {0}`; these partition `{1, …, n+1}`.

**(A3.1) Compatible matchings are products.** A pair `{j,k}` has `c_jc_k = 1` iff either `{j,k} ⊆ E`, or `{j,k}` meets both `A_ζ` and `B_ζ` for one `ζ ∈ Z`. Hence `J ∈ 𝒥` is compatible with `c` iff every pair of `J` is of one of these two kinds; equivalently, `J` restricts to a perfect matching `P` of `E` and, for each `ζ ∈ Z`, to a bijection `σ_ζ : A_ζ → B_ζ`. Conversely, every such choice `(P, (σ_ζ)_ζ)` is a compatible `J`. In particular a compatible `J` exists iff `|E|` is even and `|A_ζ| = |B_ζ|` for all `ζ ∈ Z`; call such `c` a *compatible colouring*. If `c` is not compatible, `π_c(I) = 0`.

**(A3.2) The block rings.** `R_c = ⊗_{i=1}^{n+1} R_{c,i}`, `R_{c,i} := F[t_i]/((t_i − c_i)^q)`. Group the factors: `R_c = R_E ⊗ ⊗_{ζ ∈ Z} R_ζ`, with `R_E := ⊗_{i ∈ E'} R_{c,i}` and `R_ζ := ⊗_{i ∈ A'_ζ ∪ B'_ζ} R_{c,i}` (the empty tensor product is `F`).

**(A3.3) The generators are pure tensors.** Let `c` be compatible and `J = (P, (σ_ζ))`. Each factor of (A2.5) involves the variables of one pair of `J`, hence lies in the block ring of the block containing that pair (the factor of the pair `{0, k_0}` is `t_{k_0} − 1`, which lies in `R_{c,k_0}`; the variable `t_0` does not exist). Define

- `g_P := [t_{k_0} − 1 if 0 ∈ E]·Π_{{j<k} ∈ P, 0 ∉ {j,k}} (t_k − 1)(t_jt_k − 1)^{q−1} ∈ R_E`;
- `g_{σ_ζ} := [t_{k_0} − 1 if 0 ∈ A_ζ ∪ B_ζ]·Π_{{j<k} pairs of σ_ζ, 0 ∉ {j,k}} (t_k − 1)(t_jt_k − 1)^{q−1} ∈ R_ζ`.

Then `π_c(ψ_J) = (unit)·g_P ⊗ ⊗_ζ g_{σ_ζ}`. Put `I_E := (g_P : P a perfect matching of E) ⊆ R_E` and `I_ζ := (g_σ : σ a bijection A_ζ → B_ζ) ⊆ R_ζ`.

**(A3.4) Lemma (tensor product of ideals).** *Let `R, R'` be finite-dimensional commutative `F`-algebras, `I = (g_α : α ∈ 𝒜) ⊆ R`, `I' = (g'_β : β ∈ ℬ) ⊆ R'`. Then the ideal of `R ⊗ R'` generated by `{g_α ⊗ g'_β}` is `I ⊗ I'` (the image of `I ⊗_F I' → R ⊗_F R'`, which is injective because `⊗_F` is exact), and `dim(I ⊗ I') = dim I · dim I'`.*
*Proof.* `I ⊗ I'` is spanned by the `x ⊗ x'` with `x ∈ I`, `x' ∈ I'`. Writing `x = Σ_α r_αg_α`, `x' = Σ_β r'_βg'_β` gives `x ⊗ x' = Σ_{α,β}(r_α ⊗ r'_β)(g_α ⊗ g'_β)`, which lies in the ideal generated by the `g_α ⊗ g'_β`. Conversely `I ⊗ I'` is an ideal of `R ⊗ R'`: pure tensors `r ⊗ r'` span `R ⊗ R'`, and `(r ⊗ r')(x ⊗ x') = rx ⊗ r'x' ∈ I ⊗ I'`; it contains the generators. A basis of `I` tensored with a basis of `I'` is a basis of `I ⊗ I'`. ∎

**(A3.5) Conclusion.** Units do not change the ideal generated, so by (A3.3), `π_c(I)` is generated by the pure tensors `g_P ⊗ ⊗_ζ g_{σ_ζ}` over all `(P, (σ_ζ))`; by (A3.4) applied repeatedly (the tensor product is associative),

`π_c(I) = I_E ⊗ ⊗_{ζ ∈ Z} I_ζ`,   `dim π_c(I) = dim I_E · Π_{ζ ∈ Z} dim I_ζ`.

(If `|E|` is odd, `I_E = 0`; if `|A_ζ| ≠ |B_ζ|`, `I_ζ = 0`: both consistent with `π_c(I) = 0`.)

### (A4) The colour-1 block — PROVED (given Theorem 5.3 / Theorem 5.9′ of the paper)

By Lemma 2.3(i) of the paper, whose proof uses only `char = p`, `q = p^v` and `2 ∈ F^×`, `R_{c,i} = F[t_i]/((t_i − 1)^q) = F[y_i]/(y_i^q)` with `y_i := t_i − t_i^{−1}`, and `y_i = (unit)·(t_i − 1)`. So `R_E = B_E := F[y_i : i ∈ E']/(y_i^q)`. Put `C_E := F[y_i : i ∈ E']/(y_i^{q−1})` and `Y := Π_{i ∈ E'} y_i`.

**(A4.1) Each generator is `(unit)·Y·D_P`.** For a pair `{j < k} ⊆ E'`: `t_k − 1 = (unit)·y_k`; `t_jt_k − 1 = (unit)·(y_j + y_k)` (Lemma 2.3(ii)); so `(t_k − 1)(t_jt_k − 1)^{q−1} = (unit)·y_k(y_j + y_k)^{q−1} = (unit)·y_jy_k·D(y_j, y_k)` by Lemma 2.4(i) (an identity in `F_p[a,b]/(b^q)`, hence in `B_E`), where `D(a,b) = (b^{q−1} − a^{q−1})/(a + b)`. If `0 ∈ E`, the factor of `{0,k_0}` is `t_{k_0} − 1 = (unit)·y_{k_0}`. The indices occurring in the monomial factors are exactly `E'`, each once. Hence `g_P = (unit)·Y·D_P`, `D_P := Π_{{j<k} ∈ P, 0 ∉ {j,k}} D(y_j, y_k)`.

**(A4.2) Dropping `Y`.** Multiplication by `Y` on `B_E` sends the monomial `y^α` (`0 ≤ α_i ≤ q−1`) to `y^{α+1}`, which is `0` iff some `α_i = q−1` and otherwise is a monomial, distinct monomials going to distinct monomials. Therefore

`dim I_E = dim_F (D_P : P perfect matching of E)·C_E`.

### (A5) A pair block — PROVED (the change of variables); the dimension inequality is Part B

Fix `ζ ∈ Z`, `A := A_ζ`, `B := B_ζ`. In `R_{c,i}` (`i ∈ A'`) put `x_i := ζ^{−1}t_i − 1 = ζ^{−1}(t_i − ζ)`; in `R_{c,j}` (`j ∈ B'`) put `z_j := (ζt_j)^{−1} − 1`.

**(A5.1)** *`x_i^q = 0` and `R_{c,i} = F[x_i]/(x_i^q)`.* `x_i` is a unit multiple of `t_i − ζ`, whose `q`-th power is `0` and which generates the maximal ideal of the local ring `R_{c,i} = F[t_i]/((t_i−ζ)^q)`; so `1, x_i, …, x_i^{q−1}` lie in successive powers of the maximal ideal and not in the next, are linearly independent, and span (dimension `q`). Also `t_i = ζ(1 + x_i)`.

**(A5.2)** *`z_j^q = 0` and `R_{c,j} = F[z_j]/(z_j^q)`.* Put `ε_j := ζt_j − 1 = ζ(t_j − ζ^{−1})`, nilpotent with `ε_j^q = 0`. Then `ζt_j = 1 + ε_j` is a unit and `z_j = (1 + ε_j)^{−1} − 1 = −ε_j(1 + ε_j)^{−1} = (unit)·ε_j`; the argument of (A5.1) applies. Also `t_j = ζ^{−1}(1 + z_j)^{−1}`.

**(A5.3)** *For `i ∈ A'`, `j ∈ B'`: `t_it_j − 1 = (unit)·(x_i − z_j)`.* Indeed `t_it_j = (1 + x_i)(1 + z_j)^{−1}`, so `t_it_j − 1 = ((1 + x_i) − (1 + z_j))(1 + z_j)^{−1} = (x_i − z_j)(1 + z_j)^{−1}`, and `1 + z_j` is a unit.

So `R_ζ = F[x_i (i ∈ A'), z_j (j ∈ B')]/(x_i^q, z_j^q)`, and by (A3.3), (A2.1) (every `t_k − 1` with `k ∈ A ∪ B` is a unit, since `c_k ≠ 1`):

- **balanced** (`0 ∉ A ∪ B`, `|A| = |B| = a`): `g_σ = (unit)·Π_{i ∈ A}(x_i − z_{σ(i)})^{q−1}`; relabelling `A = B = [a]`, `I_ζ ≅ I_a := (Π_{i=1}^a (x_i − z_{σ(i)})^{q−1} : σ ∈ S_a) ⊆ F[x_1..x_a, z_1..z_a]/(x_i^q, z_j^q)`;
- **phantom, `0 ∈ B`** (`|A| = a+1`, `|B'| = a`): a bijection `σ : A → B` sends exactly one `i_0 ∈ A` to `0`; the pair `{0, i_0}` (here `k_0 = i_0`) contributes the unit `t_{i_0} − 1`, and the others contribute `(x_i − z_{σ(i)})^{q−1}` up to units. So `I_ζ ≅ I'_a := (Π_{i ≠ i_0}(x_i − z_{σ(i)})^{q−1} : i_0 ∈ [a+1], σ : [a+1] ∖ {i_0} → [a] bijective) ⊆ F[x_1..x_{a+1}, z_1..z_a]/(box q)`;
- **phantom, `0 ∈ A`** (`|A'| = a`, `|B| = a+1`): symmetrically, `I_ζ ≅ (Π_{j ≠ j_0}(x_{σ(j)} − z_j)^{q−1} : j_0, σ)` in `F[x_1..x_a, z_1..z_{a+1}]/(box q)`. Since `q − 1` is even, `(x − z)^{q−1} = (z − x)^{q−1}`, and the ring isomorphism exchanging the names `x ↔ z` carries this ideal onto `I'_a`. Same dimension. ✓ (Equivalently: choosing `ζ^{−1}` instead of `ζ` as representative exchanges `A` and `B`; the ideal `I_ζ` is defined intrinsically by (A3.3), so nothing depends on the choice.)
- `a = 0`: `I_0 = (1) = F` (dimension `1`); `I'_0 = (1) = F[x_1]/(x_1^q)` (dimension `q`).

### (A6) The counts factor the same way — PROVED

**(A6.1) `Γ` and `Γ_𝒥`.** `Γ` is the set of `a = (a_1, …, a_{n+1}) ∈ μ_m^{n+1}` such that, with `a_0 := (a_1⋯a_{n+1})^{−1}`, all `a_i ≠ 1` (`i = 0..n+1`) and the multiset `{a_0, …, a_{n+1}}` splits into inverse pairs. The first paragraph of the proof of Lemma 2.2 (which uses nothing about `m`) shows `Γ = Γ_𝒥` of [DS, Definition 1.3]. Since `m` is odd, `a ≠ a^{−1}` for `a ∈ μ_m ∖ 1`, so «splits into inverse pairs» = «closed under inversion» for the multiset `{a_i} ⊆ μ_m ∖ 1`.

**(A6.2) CRT on the points.** `gcd(q, r) = 1`, so `μ_m = μ_q × μ_r`: every `a ∈ μ_m` is uniquely `a = a_{(q)}·a_{(r)}` with `a_{(q)} ∈ μ_q`, `a_{(r)} ∈ μ_r`, and `a ↦ a_{(q)}`, `a ↦ a_{(r)}` are group homomorphisms. For `a ∈ μ_m^{n+1}`, its *colouring* is `c(a) := ((a_1)_{(r)}, …, (a_{n+1})_{(r)}) ∈ μ_r^{n+1}`, and `c(a)_0 := (Π c(a)_i)^{−1} = (a_0)_{(r)}`. Write `b_i := (a_i)_{(q)}` (`i = 0..n+1`), so `b_0 = (Π_{i≥1} b_i)^{−1}` and `a_i = c_ib_i`. Two facts: `a_ia_j = 1 ⟺ c_ic_j = 1 and b_ib_j = 1`; `a_i ≠ 1 ⟺ (c_i, b_i) ≠ (1, 1)`.

**(A6.3) Only compatible colourings occur.** If `a ∈ Γ`, the pairing of `{a_i}` into inverse pairs is a perfect matching `J` of `{0..n+1}` with `c_jc_k = 1` on every pair, i.e. `J` is compatible with `c(a)`; so `c(a)` is a compatible colouring (A3.1). Hence `Γ = ⊔_{c compatible} Γ_c`, `Γ_c := {a ∈ Γ : c(a) = c}`, and `|Γ| = Σ_{c compatible} |Γ_c|`.

**(A6.4) The fibre over a compatible `c` is a product.** Fix a compatible `c`. The tuples `a` with `c(a) = c` are exactly `a_i = c_ib_i` for `b = (b_1..b_{n+1}) ∈ μ_q^{n+1}`, and then `a_0 = c_0b_0` with `b_0 := (Π_{i ≥ 1} b_i)^{−1}`. For such `a`: (i) `a_i ≠ 1` for all `i = 0..n+1` iff `b_i ≠ 1` for all `i ∈ E` (for `i ∉ E`, `c_i ≠ 1` already); (ii) `{a_i}` splits into inverse pairs iff there is a perfect matching `J` with `c_jc_k = 1` and `b_jb_k = 1` on its pairs, iff (by (A3.1)) there are a perfect matching `P` of `E` with `b_jb_k = 1` on its pairs and, for each `ζ ∈ Z`, a bijection `σ_ζ : A_ζ → B_ζ` with `b_{σ_ζ(i)} = b_i^{−1}`. The existence of such a `σ_ζ` is the condition `multiset(b_i : i ∈ A_ζ) = multiset(b_j^{−1} : j ∈ B_ζ)` (this is the correct condition even for the value `b = 1`, because a pair inside `A_ζ` would have colour product `ζ^2 ≠ 1`); the existence of `P` is «the multiset `{b_i : i ∈ E} ⊆ μ_q ∖ 1` is closed under inversion».

The only coupling between blocks is `b_0`. Let `β` be the block containing `0`. For every block `β' ≠ β`, its condition implies `Π_{i ∈ β'} b_i = 1` (the `b`'s pair off into inverse pairs). Hence, when all blocks `β' ≠ β` satisfy their conditions, `b_0 = (Π_{i ∈ β ∖ 0} b_i)^{−1}`, and the condition on `β` becomes a condition on `(b_i)_{i ∈ β ∖ 0}` alone. Therefore

`|Γ_c| = Π_{blocks β'} N(β')`,

where `N(β')` is the number of `b ∈ μ_q^{β' ∖ 0}` satisfying the block's condition, with `b_0 := (Π_{i ∈ β' ∖ 0} b_i)^{−1}` when `0 ∈ β'`. Explicitly:
- `N(E)` is the colour-1 block count of (A4.5) (the `b_i`, `i ∈ E`, range over `μ_q ∖ 1`);
- balanced pair block, `|A_ζ| = |B_ζ| = a`: `N(A_ζ ∪ B_ζ) = N(a, q) := #{(ξ, η) ∈ μ_q^a × μ_q^a : multiset(ξ) = multiset(η^{−1})} = Σ_{c_1+⋯+c_q = a} (a!/Π_s c_s!)^2` (choose the multiplicity vector `(c_s)` of the `q` values; `ξ` and `η^{−1}` are each an arrangement of it);
- phantom pair block, `0 ∈ B_ζ`, `|A_ζ| = a+1`, `|B'_ζ| = a`: with `ξ := (b_i)_{i ∈ A_ζ}`, `η := (b_j)_{j ∈ B'_ζ}` and `η_0 := b_0 = (Π ξ · Π η)^{−1}`, the condition is `multiset(ξ) = multiset(η^{−1}) ∪ {η_0^{−1}}`. **Consistency of `a_0` with the global product:** if `multiset(η^{−1}) ⊆ multiset(ξ)`, the leftover `ξ* := multiset(ξ) − multiset(η^{−1})` is one element, `Π ξ = ξ*·Π η^{−1}`, so `η_0 = (Π ξ·Π η)^{−1} = (ξ*)^{−1}` and the condition holds; conversely the condition implies `multiset(η^{−1}) ⊆ multiset(ξ)`. Hence `N = N'(a, q) := #{(ξ, η) ∈ μ_q^{a+1} × μ_q^a : multiset(η^{−1}) ⊆ multiset(ξ)}`;
- phantom with `0 ∈ A_ζ`: the same count `N'(a, q)` with `a = |A'_ζ| = |B_ζ| − 1`, by the symmetry `ξ ↔ η`, `b ↦ b^{−1}`.

So `|Γ| = Σ_{c compatible} N(E(c)) · Π_{ζ ∈ Z} N(A_ζ(c) ∪ B_ζ(c))`. ∎

### (A7) Conclusion — PROVED conditionally on the bipartite inequalities

**Proposition A7.** *Let `m` be odd, `p | m`, `m = qr` as above. Suppose that, for this `q` and every `a ≥ 0`, `dim_F I_a ≥ N(a, q)` and `dim_F I'_a ≥ N'(a, q)`. Then `dim_{F_p}(ψ̄_J : J ∈ 𝒥)F_p[G] = |Γ|`, and `H_{2k}(X; Z)/L(X)` has no `p`-torsion. If this holds for every prime `p | m`, then `H_{2k}(X; Z)/L(X)` is torsion free (Conjecture 1.2 of [DS] at `m`, in dimension `2k`).*

*Proof.* Extension of scalars: `(ψ̄_J)F[G] = (ψ̄_J)F_p[G] ⊗_{F_p} F`, so `dim_{F_p}(ψ̄_J)F_p[G] = dim_F I`. By (A1), `dim_F I = Σ_c dim π_c(I)`; by (A3.1) only compatible `c` contribute; for those, (A3.5), (A4.5), (A5) and the hypothesis give `dim π_c(I) = dim I_E · Π_ζ dim I_ζ ≥ N(E) · Π_ζ N(A_ζ ∪ B_ζ) = |Γ_c|` (A6.4). Summing, `dim_F I ≥ |Γ|` by (A6.3). By Proposition 2.1 of the paper (valid for every `m ≥ 3`, every prime `p`, and `K = 𝒥`), `dim_{F_p}(A_𝒥 ⊗ F_p) = m^{n+1} − dim_{F_p}(ψ̄_J)F_p[G] ≥ m^{n+1} − |Γ|`, with equality iff `A_𝒥` has no `p`-torsion; and `Tors(H_n(X)/L(X)) ≅ Tors(A_𝒥)` (Theorem 0(a)), whose order is divisible only by primes dividing `m` (Theorem 0(d)). Both inequalities together force `dim_F I = |Γ|`, so there is no `p`-torsion. ∎

**Remarks.** (1) Only `≥` per pair block is needed; `≤` is global (Proposition 2.1). (2) Nothing in (A1)–(A7) uses `k`, `n` or `r` beyond `r` odd: the same proof gives, for every non-empty `K ⊆ 𝒥`, `dim(ψ̄_J : J ∈ K) = Σ_c dim π_c(I_K)`, but for a subfamily `K` the compatible matchings are no longer a product set, so (A3.5) fails and the block structure is lost; consistent with §7 of the paper. (3) `m` prime power is the case `r = 1`: one colouring, `E = {0..n+1}`, and (A4.3) is the Main Theorem.

### 3.2 Two pencil facts: the count identity and the top slice — PROVED

**Lemma 3.2.1 (`N'(a,q) = N(a+1,q)`).** *For every `q ≥ 1` and `a ≥ 0`: `N'(a, q) = N(a+1, q)`.*
*Proof.* Let `(ξ, η) ∈ μ_q^{a+1} × μ_q^a` with `multiset(η^{−1}) ⊆ multiset(ξ)`. The multiset difference `multiset(ξ) − multiset(η^{−1})` has exactly one element `ξ*`; put `η_{a+1} := (ξ*)^{−1}`. Then `multiset(ξ) = multiset((η, η_{a+1})^{−1})`, so `(ξ, (η, η_{a+1}))` is a balanced point at `a+1`. Conversely, from a balanced point `(ξ, η') ∈ μ_q^{a+1} × μ_q^{a+1}`, drop the last coordinate of `η'`: the remaining `η` satisfies `multiset(η^{−1}) ⊆ multiset(ξ)`, and the dropped value is determined (`= (ξ*)^{−1}`). The two maps are mutually inverse. ∎

**Lemma 3.2.2 (peeling, box `q`).** Let `R = R'[w]/(w^q)` with `R' = F[v_1, …, v_s]/(v_i^q)`, and for an ideal `V ⊆ R` and `0 ≤ j ≤ q−1` put `V_{≤j} := {f ∈ V : deg_w f ≤ j}`, `W_j(V) := {[w^j]f : f ∈ V_{≤j}} ⊆ R'`. *Then (i) `W_j(V)` is an ideal of `R'`; (ii) `W_j(V) ⊆ W_{j+1}(V)` for `0 ≤ j < q−1`; (iii) `dim V = Σ_{j=0}^{q−1} dim W_j(V)`; (iv) for `Z ⊆ μ_q^{s+1}` (coordinate `w` first) and `M' ∈ μ_q^s`, with `F(M') := {u ∈ μ_q : (u, M') ∈ Z}` and `Z_{>i} := {M' : |F(M')| > i}`, `|Z| = Σ_{i=0}^{q−1} |Z_{>i}|`.*
*Proof.* Verbatim the proof of Lemma 5.1 of the paper, with `q − 1` replaced by `q` (in (ii) one uses `w^{j+1} ≠ 0`, i.e. `j + 1 ≤ q − 1`; in (iv), `|F(M')| ≤ q`). ∎

**Lemma 3.2.3 (the phantom ideal is contained in the top slice of the balanced ideal).** *In `F[x_1..x_{a+1}, z_1..z_{a+1}]/(box q)`, peel `w := z_{a+1}`. Then `W_{q−1}(I_{a+1}) ⊇ I'_a`, where `I'_a ⊆ F[x_1..x_{a+1}, z_1..z_a]/(box q)` is the phantom ideal. Consequently `dim I_{a+1} ≥ dim I'_a`.*
*Proof.* A generator of `I_{a+1}` is `g_σ = Π_{i=1}^{a+1}(x_i − z_{σ(i)})^{q−1}`, `σ ∈ S_{a+1}`. Let `i_0 := σ^{−1}(a+1)`. Then `g_σ = (x_{i_0} − z_{a+1})^{q−1}·Π_{i ≠ i_0}(x_i − z_{σ(i)})^{q−1}`, and `(x_{i_0} − z_{a+1})^{q−1} = Σ_{s=0}^{q−1} C(q−1, s)(−1)^s x_{i_0}^{q−1−s} z_{a+1}^s` has `z_{a+1}`-degree exactly `q − 1` with top coefficient `(−1)^{q−1} = 1`. So `g_σ ∈ (I_{a+1})_{≤ q−1}` and `[z_{a+1}^{q−1}] g_σ = Π_{i ≠ i_0}(x_i − z_{σ(i)})^{q−1}`, which is the phantom generator indexed by `(i_0, σ|_{[a+1]∖i_0})`; as `σ` runs over `S_{a+1}`, `(i_0, σ|)` runs over all `(i_0, bijection [a+1]∖{i_0} → [a])`. Since `W_{q−1}(I_{a+1})` is an ideal (3.2.2(i)) containing every phantom generator, it contains `I'_a`. Then `dim I_{a+1} = Σ_j dim W_j ≥ dim W_{q−1} ≥ dim I'_a` by 3.2.2(iii). ∎

**Consequences.** (a) *The phantom inequality implies the balanced one:* if `dim I'_a ≥ N'(a,q)` then `dim I_{a+1} ≥ N'(a,q) = N(a+1,q)` (3.2.1). (b) In the 18 measured cells, `dim I_{a+1} = dim I'_a`; by (iii) this forces `W_j(I_{a+1}) = 0` for `j < q−1` and `W_{q−1}(I_{a+1}) = I'_a` there, which is the «structural reason» behind the observation of 3.1: the map `I'_a → I_{a+1}` is «multiply the top coefficient back by `z_{a+1}^{q−1}`», an isomorphism of graded spaces of degree shift `q−1` in those cells. (Grade of (b): MEASURED; the inclusion `I'_a ⊆ W_{q−1}` is PROVED for all `a, q`.)

*Where the balanced inequality would come from by peeling.* Peel `z_a` from the balanced point set at `a`: a tail `(ξ, η') ∈ μ_q^a × μ_q^{a−1}` has fibre of size `1` if `multiset(η'^{−1}) ⊆ multiset(ξ)` (the missing value is forced) and `0` otherwise. So `Z_{>0}` is the phantom point set at `a − 1` and `Z_{>i} = ∅` for `i ≥ 1`: the balanced count is *entirely* carried by the top slice, and 3.2.3 is the exact ideal-side counterpart. Peeling `x_{a+1}` from the phantom set at `a` instead: a tail `(ξ', η) ∈ μ_q^a × μ_q^a` has fibre `q` if `multiset(ξ') = multiset(η^{−1})`, fibre `1` if `multiset(η^{−1}) − multiset(ξ')` has exactly one element, and `0` otherwise; so `Z_{>0} = {tails with «defect» ≤ 1}` and `Z_{>i} = {balanced tails}` for `1 ≤ i ≤ q−1`. On the ideal side the phantom generators with `i_0 = a+1` do not involve `x_{a+1}`, so `W_0(I'_a) ⊇ I_a` (and hence every slice contains `I_a`), while `W_{q−1}(I'_a)` contains the products over bijections `[a]∖{i_0} → [a]∖{j_0}`. To close the induction one must therefore enlarge the family to «defects», exactly as the paper enlarges matchings to down-sets of partitions. This is done in 3.3.

### 3.3 The bipartite down-set theorem — PROVED

Throughout: `F` a field of characteristic `p`, `q = p^v`, `T` a set of `q` elements (for the application, `T = μ_q`). Index sets `A` (for the `x`'s) and `B` (for the `z`'s), `α := |A|`, `β := |B|`; ring `R_{A,B} := F[x_i (i ∈ A), z_j (j ∈ B)]/(x_i^q, z_j^q)`. Points: `(ξ, η) ∈ T^A × T^B`. (In (A5)–(A6) the phantom/balanced points were written with `η^{−1}`; `η ↦ η^{−1}` is a bijection of `T^B`, so the counts are the same, and below `η` stands for what was `η^{−1}`.) For a partition `λ`, `S_t(λ)` is the sum of its `t` largest parts, `ℓ(λ)` its length, `λ'_c` its column lengths, `≼` weak dominance (`λ ≼ μ` iff `S_t(λ) ≤ S_t(μ)` for all `t`), all as in §5.2 of the paper; `r̄_j(λ)` and `r̲_j(λ)` are the last and the first row of `λ` of length `λ_j`.

**Definitions.**
- **Residue shape.** For `(ξ, η)`, let `X`, `Y` be the multisets of values of `ξ`, `η`, and `R_+ := X ∖ Y`, `R_− := Y ∖ X` (multiset differences: `R_+` keeps, for each value `u` with `mult_X(u) > mult_Y(u)`, `mult_X(u) − mult_Y(u)` copies of `u`; similarly `R_−`). `λ_+(ξ,η)` and `λ_−(ξ,η)` are the multiplicity partitions of `R_+` and `R_−`. The supports of `R_+` and `R_−` are disjoint subsets of `T`, so `ℓ(λ_+) + ℓ(λ_−) ≤ q`; `|λ_+| − |λ_−| = |X| − |Y| = α − β`; `|λ_+| + |λ_−| ≤ α + β`.
- `Par_q(α, β) := {(λ_+, λ_−) : |λ_+| − |λ_−| = α − β, |λ_+| + |λ_−| ≤ α + β, ℓ(λ_+) + ℓ(λ_−) ≤ q}`. **Order:** `(λ_+, λ_−) ≼ (μ_+, μ_−)` iff `λ_+ ≼ μ_+` and `λ_− ≼ μ_−` (product of two weak dominance orders; a partial order).
- For a `≼`-down-set `Λ ⊆ Par_q(α, β)`: `Z_Λ := {(ξ, η) ∈ T^A × T^B : (λ_+, λ_−)(ξ, η) ∈ Λ}`.
- **Tight pattern** of `λ = (λ_+, λ_−) ∈ Par_q(α, β)` on `(A, B)`: a set `P` of pairwise disjoint pairs `(i, j) ∈ A × B` with `|P| = α − |λ_+| = β − |λ_−|`; blocks `B^+_1, …, B^+_{λ_{+,1}}` partitioning `A ∖ A(P)` with `|B^+_c| = (λ_+)'_c`; blocks `B^−_c` partitioning `B ∖ B(P)` with `|B^−_c| = (λ_−)'_c`. (Such patterns exist: `|λ_+| ≤ α` and `|λ_−| ≤ β` follow from the two size conditions.) Its **product** is
  `Π_{(i,j) ∈ P} (x_i − z_j)^{q−1} · Π_c Δ(x_{B^+_c}) · Π_c Δ(z_{B^−_c})`,
  where `Δ` of a block of variables `{v_{b_1}, …, v_{b_r}}` (`b_1 < ⋯ < b_r`) is the Vandermonde determinant `Π_{c<c'}(v_{b_{c'}} − v_{b_c})` (`Δ = 1` for blocks of size `≤ 1`).
- `V_Λ ⊆ R_{A,B}` is the ideal generated by the products of all tight patterns on `(A, B)` of all `λ ∈ Λ`. For `α = β = 0` the empty product is `1`.

**The roots.** (i) `Λ = {(∅, ∅)} ⊆ Par_q(a, a)` is a down-set (only `(∅,∅)` is `≼ (∅,∅)`, since `S_1(λ) ≤ 0` forces `λ = ∅`); a tight pattern of `(∅, ∅)` is a perfect matching of `A` with `B` (no blocks), so `V_Λ = I_a`; `Z_Λ = {X = Y}`, of size `N(a, q)`. (ii) `Λ = {((1), ∅)} ⊆ Par_q(a+1, a)` is a down-set: `(λ_+, λ_−) ≼ ((1), ∅)` forces `λ_− = ∅` and `λ_+ ∈ {∅, (1)}`, and `|λ_+| − |λ_−| = 1` forces `λ_+ = (1)`; a tight pattern has `a` pairs and one `x`-block of size `1` (`Δ = 1`), so `V_Λ = I'_a`; `Z_Λ = {Y ⊆ X}`, of size `N'(a, q)`.

> **THEOREM BP.** *For every field `F` of characteristic `p`, every `q = p^v`, all `α, β ≥ 0` and every `≼`-down-set `Λ ⊆ Par_q(α, β)`: `dim_F V_Λ ≥ |Z_Λ|`.*

> **COROLLARY BP.** *`dim I_a ≥ N(a, q)` and `dim I'_a ≥ N'(a, q)` for all `a ≥ 0` and all `q = p^v`, `p` odd. Hence, by Proposition A7, **Conjecture 1.2 of Degtyarev–Shimada holds for every odd `m` in every even dimension `2k`.***

*Proof of the Corollary.* The roots (i), (ii) and Theorem BP; then (A7) for each prime `p | m`. ∎

**Proof of Theorem BP.** Induction on `α + β`, with `F`, `q`, `T` fixed.

**Symmetry and relabelling.** The `F`-algebra isomorphism `R_{A,B} → R_{B,A}` exchanging the names `x ↔ z` carries the product of a tight pattern of `(λ_+, λ_−)` on `(A,B)` to the product of a tight pattern of `(λ_−, λ_+)` on `(B,A)` (`(x − z)^{q−1} = (z − x)^{q−1}` as `q − 1` is even; the Vandermondes are carried to Vandermondes of the same blocks); on points, `(ξ, η) ↦ (η, ξ)` exchanges `λ_+ ↔ λ_−`. So the statement for `(α, β, Λ)` is equivalent to the statement for `(β, α, Λ^{swap})`. A relabelling of `A` or of `B` sends every tight-pattern product to `±` another one and preserves `|Z_Λ|`. Hence we may assume `α ≥ 1` whenever `α + β ≥ 1`, and peel any chosen `x`-variable.

**Base `α + β = 0`.** `Par_q(0,0) = {(∅,∅)}`; for `Λ = ∅` both sides are `0`; for `Λ = {(∅,∅)}`, `V_Λ = (1) = F` and `Z_Λ = T^0`, one point. ✓

**Step.** Let `α ≥ 1`, fix `i_1 ∈ A`, write `x_0 := x_{i_1}`, `A' := A ∖ {i_1}`, and peel `x_0` with Lemma 3.2.2 (`w = x_0`, `R' = R_{A',B}`). Fix a down-set `Λ ⊆ Par_q(α, β)`.

*(P1) Fibres depend only on the shape.* Let `M' = (ξ', η) ∈ T^{A'} × T^B` have shape `μ = (μ_+, μ_−) ∈ Par_q(α−1, β)`, with residual values `u_1, …, u_{ℓ_+}` in `R_+` (row `j` of `μ_+` is the multiplicity of `u_j`) and `v_1, …, v_{ℓ_−}` in `R_−`. Adding the value `u ∈ T` at the index `i_1` gives the shape:
- `u = v_j`: `mult_X(u)` rises by one while `mult_Y(u) > mult_X(u)`, so `R_−` loses one copy of `v_j`: `(μ_+, μ_− − e_j)` (one box removed from row `j` of `μ_−`, re-sorted);
- `u = u_j`: `(μ_+ + e_j, μ_−)`;
- `u ∉ {u_i} ∪ {v_j}`: before, `mult_X(u) = mult_Y(u)`; after, `R_+` gains one copy of `u`: `(μ_+ ⊔ 1, μ_−)`. There are `q − ℓ_+ − ℓ_−` such `u`.
These are `ℓ_− + ℓ_+ + (q − ℓ_+ − ℓ_−) = q = |T|` values, and every option lies in `Par_q(α, β)` (sizes `|μ_+| − |μ_−| + 1 = α − β`, total size `≤ α + β`, lengths: a new part occurs only when `ℓ_+ + ℓ_− < q`). Hence `|F(M')| = F_Λ(μ)`, where
`F_Λ(μ) := #{j : (μ_+, μ_− − e_j) ∈ Λ} + #{j : (μ_+ + e_j, μ_−) ∈ Λ} + (q − ℓ_+ − ℓ_−)·[(μ_+ ⊔ 1, μ_−) ∈ Λ]`,
and `Z_{>i} = Z_{Λ_i}` with `Λ_i := {μ ∈ Par_q(α−1, β) : F_Λ(μ) > i}`.

*(Chain) The options form a chain.* List the `q` options by position `p = 1, …, q`: `opt_p(μ) := (μ_+, μ_− − e_p)` for `p ≤ ℓ_−`; `(μ_+ ⊔ 1, μ_−)` for `ℓ_− < p ≤ q − ℓ_+` («middle positions»); `(μ_+ + e_{q+1−p}, μ_−)` for `p > q − ℓ_+`. By the identities of §5.5 of the paper (`S_t(λ − e_j) = S_t(λ) − [t ≥ r̄_j]`, `S_t(λ + e_j) = S_t(λ) + [t ≥ r̲_j]`, `S_t(λ ⊔ 1) = S_t(λ) + [t > ℓ(λ)]`): `μ_− − e_1 ≼ ⋯ ≼ μ_− − e_{ℓ_−} ≼ μ_−` (rows are sorted, so `r̄_j` is non-decreasing), `μ_+ ≼ μ_+ ⊔ 1 ≼ μ_+ + e_{ℓ_+} ≼ ⋯ ≼ μ_+ + e_1` (`r̲_{ℓ_+} ≤ ℓ_+ < t` whenever `[t > ℓ_+] = 1`; `r̲_j` non-decreasing). In the product order the listed options are therefore weakly increasing: the first component is constant along the removals and the second along the middle and the additions. Since `Λ` is a down-set, the options in `Λ` form an initial segment of the chain and `F_Λ(μ)` is its length. Consequently the removals in `Λ` are `μ_− − e_p` for `p ≤ r`, where `r = 0` or `r` is the last row of `μ_−` of its length (equal rows give equal options); the additions in `Λ` are `μ_+ + e_j` for `j_0 ≤ j ≤ ℓ_+`, with `j_0` (if it exists) the first row of `μ_+` of its length; put `ι := [(μ_+ ⊔ 1, μ_−) ∈ Λ]` (`ι = 0` if `ℓ_+ + ℓ_− = q`). If `j_0` exists then `r = ℓ_−` and every middle option is in `Λ`; if `ι = 1` then `r = ℓ_−`. Hence
`F_Λ(μ) = r + (q − ℓ_+ − ℓ_−)·ι + (ℓ_+ − j_0 + 1)·[j_0 exists]`,   (BP.1)
and in particular `F = q − j_0 + 1` if `j_0` exists (whether or not middle options exist), `F = q − ℓ_+` if `ι = 1` and no `j_0`, and `F = r` otherwise.

*(P2) The layers are down-sets.* **Claim:** *if `μ ≼ μ̃` in `Par_q(α−1, β)` then `opt_p(μ) ≼ opt_p(μ̃)` for every `p`.* Then `opt_p(μ̃) ∈ Λ ⟹ opt_p(μ) ∈ Λ`, so `F_Λ(μ) ≥ F_Λ(μ̃)` and each `Λ_i` is a down-set. Write `ℓ_± = ℓ(μ_±)`, `ℓ̃_± = ℓ(μ̃_±)`. Each position `p` has a type for `μ` (removal `R`, middle `M`, addition `A`) and a type for `μ̃`. Two facts from the paper are used: **(T)** at a tight `t` (`S_t(λ) = S_t(λ̃)` with `λ ≼ λ̃`), `λ_t ≥ λ̃_t` and `λ_{t+1} ≤ λ̃_{t+1}`; and **(5.2)**: if `λ ≼ λ̃` and `ℓ(λ) < t ≤ ℓ(λ̃)` then `S_t(λ̃) ≥ |λ| + (t − ℓ(λ))`. Also the one-partition comparisons proved in Proposition 5.6 of the paper, which use only `λ ≼ λ̃` (no parity, no cap): **(a)** `λ − e_p ≼ λ̃ − e_p` for `p ≤ min(ℓ, ℓ̃)`; **(b)** `λ + e_j ≼ λ̃ + e_j` for `j ≤ min(ℓ, ℓ̃)`; **(c)** `λ ⊔ 1 ≼ λ̃ ⊔ 1`; **(e2)** `λ + e_j ≼ λ̃ ⊔ 1` for `ℓ̃ < j ≤ ℓ`. - **AA** (`j = q+1−p ≤ min(ℓ_+, ℓ̃_+)`): (b) for `μ_+ ≼ μ̃_+`; `μ_− ≼ μ̃_−`.
- **MM**: (c) for `μ_+ ≼ μ̃_+`; `μ_− ≼ μ̃_−`.
- **RM** (`p ≤ ℓ_−`, `p` middle for `μ̃`): `(μ_+, μ_− − e_p) ≼ (μ_+, μ_−) ≼ (μ̃_+, μ̃_−) ≼ (μ̃_+ ⊔ 1, μ̃_−)`.
- **RA**: `μ_+ ≼ μ̃_+ ≼ μ̃_+ + e_j` and `μ_− − e_p ≼ μ_− ≼ μ̃_−`.
- **MR** (`ℓ_− < p ≤ ℓ̃_−`, so `ℓ_− < ℓ̃_−`): need `μ_+ ⊔ 1 ≼ μ̃_+` and `μ_− ≼ μ̃_− − e_p`. By (5.2) at `t = ℓ̃_−`, `|μ̃_−| ≥ |μ_−| + 1`, hence `|μ̃_+| = |μ̃_−| + (α − 1 − β) ≥ |μ_+| + 1`. *First:* for `t ≤ ℓ_+`, `S_t(μ_+ ⊔ 1) = S_t(μ_+) ≤ S_t(μ̃_+)`; for `t > ℓ_+`, `S_t(μ_+ ⊔ 1) = |μ_+| + 1`, and `S_t(μ̃_+) ≥ |μ_+| + 1` (if `t ≥ ℓ̃_+` it is `|μ̃_+|`; if `ℓ_+ < t < ℓ̃_+` it is `≥ S_{ℓ_+}(μ̃_+) + (t − ℓ_+) ≥ |μ_+| + 1`). *Second:* for `t < r̄̃_p` the bracket vanishes and dominance suffices; for `t ≥ r̄̃_p ≥ p > ℓ_−`, `S_t(μ_−) = |μ_−|` while `S_t(μ̃_−) ≥ S_{ℓ_−}(μ̃_−) + 1 ≥ |μ_−| + 1` (row `ℓ_− + 1 ≤ p ≤ ℓ̃_−` of `μ̃_−` is non-empty and `t ≥ p`).
- **MA** (`p` middle for `μ`, addition for `μ̃` with `j = q+1−p`; then `j ≥ ℓ_+ + 1` and `j ≤ ℓ̃_+`, so `ℓ_+ < ℓ̃_+`): need `μ_+ ⊔ 1 ≼ μ̃_+ + e_j`; `μ_− ≼ μ̃_−` is given. Suppose `t` is tight. Rows `r̲_j, …, j` of `μ_+` all have length `m := μ_{+,j} ≥ 1`, so `μ_{+,t} = μ_{+,t+1} = m` (as `t < t+1 ≤ j`).
