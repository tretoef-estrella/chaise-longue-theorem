### THEOREM R1. For every `k ≥ 0`, (S) holds at `q = 3`: `dim_{F_3}(D_J : J ∈ J)·C = C(2k+2, k+1) = Q_k(3)`. Hence Conjecture 1.2 of [DS] holds for the cubic Fermat variety of every even dimension `2k`.
Moreover the graded ranks are `C(n,u) − C(n,u+2)` in degree `u = k..n` (`n = 2k+1`), and the deglex leading-monomial
set of `(D_J)C` is exactly `𝓤 := {y_U : the path of U never goes below −1}` (defined below).

**Proof.** `n = 2k+1`, `C = F_3[y_1..y_n]/(y_i^2)`, basis the squarefree monomials `y_U`, `U ⊆ [n]`. For a matching
`J` write `c = k_0` for the partner of `0` and `(a,b)`, `a < b`, for the other `k` pairs; `D_J = Π_{(a,b)}(y_b − y_a)`
(§1.3; `D(a,b) = b − a` at `q = 3`). Order monomials by lex with `y_1 > y_2 > ⋯ > y_n`.

*(i) The certificate elements.* For `T ⊆ [n]`, `y_T·D_J = Π_{(a,b)} f_{a,b} · y_c^{[c∈T]}`, where `f_{a,b} = y_b − y_a` if
`{a,b} ∩ T = ∅`, `f = y_ay_b` if `a ∈ T ∌ b`, `f = −y_ay_b` if `b ∈ T ∌ a`, `f = 0` if `{a,b} ⊆ T` (because `y^2 = 0`).
The factors live on disjoint sets of variables, so the expansion of a nonzero `y_T·D_J` has `2^{#untouched pairs}`
distinct squarefree monomials with coefficients `±1`. Among them the lex-largest is the one choosing `−y_a` in every
untouched pair: two such monomials differ first at the smallest element of a pair where they differ, which is an
`a`. So `LM(y_T D_J) = y_U` with coefficient `±1`, where `U = {a : (a,b) untouched} ∪ ⋃_{touched}{a,b} ∪ ({c} ∩ T)`.

*(ii) Which `U` are reached.* Read `i = 1..n`; put `(` for `i ∈ U`, `)` for `i ∉ U`, and match parentheses greedily
(a `)` is matched to the nearest unmatched `(` before it). Let `h(i) = #(U∩[i]) − #([i]∖U)`; the number of unmatched
`)` is `−min(0, min_i h(i))`. Suppose `min h ≥ −1`, i.e. at most one unmatched `)`.
- If there is one, call it `c`; the unmatched `(` are `|U| − (n−|U|−1) = 2|U| − n + 1` elements of `U`, an even number.
- If there is none, `2|U| − n` unmatched `(` remain; this number is odd (n odd) and `≥ −1`, hence `≥ 1`: call the
  largest of them `c`; an even number remains.
Pair the remaining unmatched `(` among themselves (consecutively) into "full pairs". The matched pairs `(a,b)`
(`a ∈ U`, `b ∉ U`, `a < b`), the full pairs and `{0,c}` form a matching `J ∈ J`. Put `T` = {the smaller element of
each full pair} ∪ ({c} ∩ U). Then every matched pair is untouched, every full pair is touched once, and by (i)
`LM(y_T D_J) = ±y_U`. Conversely every `U` of (i) has `min h ≥ −1` (its `)`'s, except possibly `c`, are the `b`'s of
untouched pairs, each matchable to its own `a`), so the reachable set is exactly `𝓤`.

*(iii) Counting.* Paths of length `n` with steps `±1`, ending at `h = 2u − n`, of which `C(n,u)`. Those that reach
`−2` are in bijection (reflection of the part after the first visit to `−2`) with paths ending at `−4 − h`, i.e. with
`u' = n − u − 2` up-steps: `C(n, u+2)` of them. For `u ≤ k−1` the end `h ≤ −3` already forces a visit to `−2`. So
`#{U ∈ 𝓤 : |U| = u} = C(n,u) − C(n,u+2)` for `u ≥ k`, and `0` for `u < k`. Summing (telescoping in steps of 2):
`Σ_{u≥k} = C(n,k) + C(n,k+1) = C(2k+2, k+1)`.

*(iv) Conclusion.* Elements of a subspace with pairwise distinct leading monomials are linearly independent (the
matrix is triangular with diagonal `±1`), in any characteristic. So `dim(D_J)C ≥ |𝓤| = C(2k+2,k+1)`. The reverse
inequality is §1.3 (Step 1: `dim_{F_3} ≥ dim_Q`, Claim 4.3), and `Q_k(3) = C(2k+2,k+1)` (§1.2). Equality forces every
leading monomial of `(D_J)C` to lie in `𝓤` and the graded ranks to be `C(n,u) − C(n,u+2)`. ∎

- **Uses the full family:** `𝓤` needs the matchings built in (ii), which are arbitrary; for a subfamily the
  argument only gives `|⋃_{J∈K} LM-sets|`, which can be `< |Γ_K|` (e.g. `k = 1`, `K = {c=2, c=3}`: 4 < 6, although
  there the dimension is still 6). No conflict with §2.3.

### 3.1 The peeling identity (PROVED, elementary)
Let `V ⊆ C_m` be an ideal. Write `C_m = C_{m−1}[y_1]/(y_1^{q−1})` with `C_{m−1}` in `y_2..y_m`, and put
`W_j(V) := {[y_1^j]f : f ∈ V, deg_{y_1} f ≤ j}` (`0 ≤ j ≤ q−2`), an ideal of `C_{m−1}`. Then
- **`dim V = Σ_j dim W_j(V)`** (`W_j ≅ V_{≤j}/V_{≤j−1}`);
- **`W_j ⊆ W_{j+1}`** (multiply by `y_1`; `y_1^{j+1} ≠ 0` for `j+1 ≤ q−2`).

For `Z ⊆ T^m`, `π` = forget `y_1`, fibre `F(M') := {y_1 : (y_1,M') ∈ Z}`, `Z_{>i} := {M' : |F(M')| > i}`:
**`|Z| = Σ_{i=0}^{q−2} |Z_{>i}|`** (each `M'` is counted `|F(M')|` times).

**Peeling Theorem.** Suppose to every node `(m, Z)` of a finite tree an ideal `V_Z ⊆ C_m` is attached, the root being
`(2k+1, Γ')` with `V = (D_J : J ∈ J)C`, leaves `m = 0` with `V = F_3` if `Z ≠ ∅`, and the children of `(m,Z)` being
`(m−1, Z_i)`, `i = 0..q−2`, with **(a)** `Z_{>i} ⊆ Z_i` and **(b)** `W_{q−2−i}(V_Z) ⊇ V_{Z_i}`. Then `dim V_Z ≥ |Z|`
at every node; at the root `dim(D_J)C ≥ Q_k(q)`, hence (S).
*Proof.* Induction on `m`: `dim V_Z = Σ_i dim W_{q−2−i} ≥ Σ_i dim V_{Z_i} ≥ Σ_i |Z_i| ≥ Σ_i |Z_{>i}| = |Z|`. ∎

### 3.2 Pattern ideals and the four constructions (PROVED)
A **type** is `(s, β)`: `s ≥ 0` and a multiset `β` of block sizes `≥ 2`. A pattern of type `(s,β)` in `[m]` is a set
`P` of `s` disjoint pairs and disjoint blocks `B_1, …` (sizes `β`), disjoint from `P`; its product is
`g = D_P · Π_t Δ(B_t)`, `D_P = Π_{(a<b)∈P} D(y_a,y_b)`, `Δ(B) = Π_{a<b ∈ B}(y_a − y_b)` (Vandermonde). As a function
on `T^m`, `g ≠ 0` exactly where `y_b = −y_a` on `P` and the values are pairwise distinct inside each block. For a set
`𝒫` of types: `𝒱(m;𝒫)` = ideal of `C_m` generated by all pattern products of types in `𝒫`;
