### 0.1 The rows of a casilla, EXACTLY (PROVED, pencil) — the algebraic form of the descent
Let `K = (e_odd(x)) + box + M ⊆ S_{n+1}`, `z := x_{n+1}`, `y := (x_1..x_n)`, and suppose `M` is generated by elements of the form `z^i·g(y)` (true for every casilla of the one-part line: `M = N_{m−1}(n+1)` monomials). Write `M^{[i]} := {g ∈ S_n : z^i g ∈ M}` (so `M^{[0]} ⊆ M^{[1]} ⊆ …`). Since `e_j(y,z) = e_j(y) + z·e_{j−1}(y)`, an element of `K + (z^{a+1})` is `Σ_r c_r·(e_{2r+1}(y) + z·e_{2r}(y)) + b + m mod z^{a+1}` with `c_r = Σ_i z^i c_r^i`, `c_r^i ∈ S_n`. Comparing the coefficients of `z^0, …, z^a`:
> **Row formula.** `f ∈ R_a(K)` iff there are `c^0, …, c^{a−1} ∈ S_n^{#odd}` with
> `Σ_r c_r^0 e_{2r+1} ∈ box + M^{[0]}`, and for `1 ≤ i ≤ a−1`: `Σ_r c_r^i e_{2r+1} + Σ_r c_r^{i−1} e_{2r} ∈ box + M^{[i]}`,
> and finally **`f ≡ Σ_r c_r^{a−1} e_{2r}(y)` mod `(e_odd) + box + M^{[a]}`.**
So `R_a(K) = (e_odd) + box + M^{[a]} + Sh_a(M)`, where `Sh_a(M)` («shadows of order a») is the set of the `Σ c^{a−1}_r e_{2r}` above. The map `e_{2r+1} ↦ e_{2r}` is the `z`-derivative of `E_{(y,z)}(T) = (T+z)E_y(T)` at `z = 0`. For the one-part line `M^{[0]} = N_{m−2}(n)` (`z ∈ B`), `M^{[i]} = Ñ_{m−1}(n)` for `1 ≤ i ≤ q−2` (`z ∈ C`; `Ñ` adds `e_n(y)` when `n+1` is even and `m ≥ 1`), `M^{[q−1]} = N_m(n)` (`z ∈ A`), where **`N_w(n)`** := the ideal of the monomials `x_Cx_A^{q−1}` of weight `|B| − |A| ≤ w` (the layer of §3.2 is exactly `N_{m−1}`: moving an index from `B` to `C`, or from `C` to `A`, gives a multiple). Rows `a = 1` and `a = q−1` of §3.2 are the cases `c^0 = 0` (resp. `c^{q−2} = 0`) of this formula; the generic row is the `a = 2` case: **`R_2(K_(m)(n+1)) = K_(m)(n) + {Σ_r c^1_r e_{2r} : Σ c^0_r e_{2r+1} ∈ box + N_{m−2}(n), Σ c^1_r e_{2r+1} + Σ c^0_r e_{2r} ∈ box + Ñ_{m−1}(n)}`**, equivalently
> **`R_2(K_(m)(n+1)) = π_z( (I^{(n+1)} + N_{m−2}(n) + z·Ñ_{m−1}(n) + (z³)) : z² )`.**
This is why the «sum of colons» of §6 is too small: the shadows come from *mixed* certificates (a monomial `zτ` of the layer paid by `e_odd(y,z)`), never from `I : z²` or `M : z²` separately.

### 0.2 Iterated rows are lex-staircase colons (PROVED, pencil) — what a «casilla» is
For a path of rows `a = (a_N, …, a_{n+1})` (variable `z_N` first): `R_{a_{n+1}}(⋯R_{a_N}(I^{(N)})⋯) = {f ∈ S_n : z^a f ∈ I^{(N)} + J_a}` with `J_a = (z^b : b >_lex a)` (`z_N ≻ … ≻ z_{n+1}`); proof by induction on the length, `f ∈ R_b(R_c(I)) ⟺ ∃h: z_1^c(z_2^b f + z_2^{b+1}h) ∈ I + (z_1^{c+1})`. The simultaneous colon `π(I^{(N)} : z^a)` is *smaller* (for `N = 2` it has `q(q+1)/2` non-vanishing exponents against `|W_∅(2)| = q`), so a tautological induction on it is dead; the content of `T(n)` is that explicit ideals *inside* the iterated rows have the right colength.
