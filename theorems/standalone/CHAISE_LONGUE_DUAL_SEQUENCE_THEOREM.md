# THE DUAL SEQUENCE THEOREM FOR THE MATCHING ARRANGEMENT
## `0 → ⊕_J S/I_J(−(k+1)) → S/E(k²−1) → ω_C → 0`
### Chaise Longue campaign — standalone deposit v1
**Author:** Lacassagne (constructor) · **Commissioned and audited by:** Orfila (auditor, mission #27 asalto B) · **Architect:** Rafa · 27 Jul 2026

---

## ABSTRACT

Let `n = 2k+2`, `S = K[x_1,…,x_n]`, `char K ≠ 2`, let `L_J` be the `(2k+1)!!` matching sheets,
`I_J` their ideals, `E = ⋂_J I_J`, and let

>   `C := coker( S/E ↪ ⊕_J S/I_J )`

be the arrangement defect module, in which the obstruction to `GAP 3` condition (I) lives
(`DEFECT_TOR_LOCALIZATION_THEOREM_v1`).

> ### **THEOREM.** For every `k`, the following sequence of graded `S`-modules is exact:
> ### `0 ⟶ ⊕_J S/I_J(−(k+1)) ⟶ S/E(k²−1) ⟶ ω_C ⟶ 0`.
> ### The statement is **unconditional**: the derivation uses only `dim C = k` and the fact that
> ### `S/E` and each `S/I_J` are complete intersections. **It does not assume `C` is Cohen–Macaulay.**

Consequence: condition (I), which is a **surjectivity** of Koszul homology, acquires a **dual
formulation as an injectivity on canonical modules**, in the category where the Gorenstein duality
`(★)` (Prop 1.4/1.5) — the machinery that closed the Sofa (dim 4) and the Hammock (dim 6) — operates.

---

## 1 · PROOF

Start from the defining sequence `0 → S/E → ⊕_J S/I_J → C → 0` and apply `Ext^•_S(−, ω_S)`.

**(a) The two left-hand modules are Gorenstein of dimension `k+1`.** `E` is a complete intersection
of degrees `1, 3, …, 2k+1` (so `codim = k+1`), and each `I_J` is generated by `k+1` linear forms
(so `S/I_J` is a polynomial ring in `k+1` variables). Both are Cohen–Macaulay, hence
`Ext^i(−, ω_S) = 0` for `i ≠ k+1`, and `Ext^{k+1}` is the canonical module.

**(b) `Ext^i(C, ω_S) = 0` for `i < k+2`.** By Grothendieck vanishing, `Ext^i(M, ω_S) = 0` for
`i < codim M`; here `dim C = k` (`DEFECT_DEGREE_THEOREM_v1`), so `codim C = n − k = k+2`.
**In particular `Ext^{k+1}(C, ω_S) = 0`** — and this is the only fact about `C` the proof needs.

**(c) The long exact sequence collapses.** Writing the contravariant long exact sequence and
inserting (a) and (b) at spots `k+1` and `k+2`:

>   `Ext^{k+1}(C) = 0 → Ext^{k+1}(⊕_J S/I_J) → Ext^{k+1}(S/E) → Ext^{k+2}(C) → Ext^{k+2}(⊕_J S/I_J) = 0`

which is exactly

>   `0 → ⊕_J ω_{S/I_J} → ω_{S/E} → ω_C → 0`.   ∎

**(d) The shifts.** For a complete intersection `R = S/(f_1,…,f_c)` in `n` variables,
`ω_R = R(Σd_i − n)`.
- `S/E`: `Σd_i = 1+3+⋯+(2k+1) = (k+1)²`, `n = 2k+2` ⟹ shift `(k+1)² − (2k+2) = **k²−1**`.
- `S/I_J`: `Σd_i = k+1` ⟹ shift `(k+1) − (2k+2) = **−(k+1)**`. ∎

## 2 · VERIFICATION (independent, two ways)

**(i) Functional equation.** A graded Gorenstein quotient satisfies `H(1/t) = (−1)^{dim} t^{a} H(t)`
with `a` the `a`-invariant. Computed symbolically for `S/E` at `k = 2, 3, 4, 5`:

| `k` | `Σd_i` | `= (k+1)²` | `n` | functional equation gives | `k²−1` | agree |
|---|---|---|---|---|---|---|
| 2 | 9 | ✓ | 6 | `t^{−3}` | 3 | ✓ |
| 3 | 16 | ✓ | 8 | `t^{−8}` | 8 | ✓ |
| 4 | 25 | ✓ | 10 | `t^{−15}` | 15 | ✓ |
| 5 | 36 | ✓ | 12 | `t^{−24}` | 24 | ✓ |

**Four cells, four agreements.** The shifts are pinned by machine, not read off by hand.

**(ii) Hilbert function cross-check (`k = 2`).** The sequence forces
`HF(ω_C)(d) = HF(S/E)(d+3) − 15·HF(S/I)(d−3)`. Computed: `34, 65, 110, 155, 200, 245, 290, …`,
with successive differences `31, 45, 45, 45, 45, …`. The differences stabilise at **`45 = deg C`**
and the stabilisation order gives **`dim 2 = dim C`**; the function is **non-negative in every
degree**, as a Hilbert function must be. Reproducer: `dual_shifts.py`.

## 3 · WHAT THIS BUYS, AND WHAT IT DOES NOT

**Buys.** Condition (I) reads `Tor_1(⊕_J S/I_J, B) ↠ Tor_1(C, B)` with `B = S/m^{[q]}` — a
surjectivity. The theorem supplies the dual side of the same configuration, in which `S/E` and the
`S/I_J` are Gorenstein and `ω_C` is the only unknown. This is precisely the setting of the
campaign's `(★)` duality (Prop 1.4/1.5), deposited and used to close dimensions 4 and 6, and never
yet applied to this object.

**Does not.**
1. **It does not prove (I), nor `GAP 3`, nor any part of the surjectivity.** `G` remains `4`.
2. It does not compute `ω_C` beyond its Hilbert function at `k = 2`, and gives no presentation.
3. It does not require, use, or establish that `C` is Cohen–Macaulay. (`C`-CM is separately
   **MEASURED** at `k = 2` — free resolution, `pd = 4`, identical Betti table in char 0 and char 3 —
   and at `k = 3` — Serre multiplicity, `length(C/sop) = 630 = deg C`. **It is not proved for all `k`.**)
4. The application of `(★)` is **not** performed here (mission #27 asalto C, not delivered, motive recorded).
5. `char K ≠ 2` is inherited from the `STRATUM_CLASSIFICATION_THEOREM`.
