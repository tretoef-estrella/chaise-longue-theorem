# 1 · SETUP

`K = F_3`, `n = 2k+2`, `q = 3^v` odd, `S' = K[x_0,…,x_{2k}]`, `m'^{[q]} = (x_0^q,…,x_{2k}^q)`.
> ### `E'_k := (e_1, e_3, …, e_{2k+1})` — the **odd** elementary symmetric polynomials · `J_0 := E'_k + m'^{[q]}`.

`V_1 := V(E)(F_q) ∩ {x_{n−1} = 1}` is the **slice**, a finite set of `N_k(q)` points; `I(V_1)` its vanishing ideal; `gr I(V_1)` the ideal of top forms; and `R(V_1) = S'/gr I(V_1)` the **orbit harmonics ring** (Li–Liu–Rhoades, arXiv:2607.28157).

`D_k^{bal}` denotes the ideal generated by the top forms of the **balanced parity detectors**
> ### `G_{A,B} = (∏_{l∉T} x_l)[(−1)^{|A|}∏_{a∈A}(1+x_a^{q−1}) − (−1)^{|B|}∏_{b∈B}(1+x_b^{q−1})]`, with `|A| = |B|`, `T = A ∪ B`.

Write `I := J_0 + D_k^{bal}`, `R := S'/I`, `B := S'/J_0`, `Λ := K[z]/(z^q)` and `z := x_{2k}`.

**Banked, used below.** `Λ` is Frobenius local; `T = S'/m'^{[q]}` is `Λ`-**free** (`OM-1`); `Ω J_s = J_{q−s}`; and the *conjecture chain* states that if `dim_K R ≤ N_k(q)` then `gr I(V_1) = I ⊆ J_1`, which is Conjecture 1.2 at level `k`.

# 2 · `THEOREM A` — THE LAYERS ARE THE JORDAN TYPE *(`PROVED`, all `k`, all odd `q`)*

For `e ≥ 0` put `c_e := dim_K S'/((I : z^e) + (z))`.

> ### **THEOREM A.** `c_e = dim_K(z^e R) − dim_K(z^{e+1} R) = #{Jordan blocks of z on R of size > e}`.
> ### **Hence `(c_e)_{e≥0}` is the CONJUGATE PARTITION of the Jordan type of multiplication by `z` on `R`.**

**Proof.** The map `S' → z^e R / z^{e+1} R`, `f ↦ z^e f`, is surjective. Its kernel is `(I : z^e) + (z)`: indeed `f ∈ (I : z^e)` iff `z^e f ∈ I` iff `f·z^e = 0` in `R`, and any `f ∈ (z)` acts as zero on `z^e R / z^{e+1} R`. Taking dimensions gives the first equality; the second is the standard count of a nilpotent operator. ∎

**In graded reverse lexicographic order with `z` smallest, `(in(I) : z^e) = in(I : z^e)` (Bayer–Stillman), which turns this count into a count of standard monomials by the exponent of `z`.**

> ### **CONSEQUENCE.** The measured profile `\big(c_0;\;c_1;\;c_{\rm mid}\times(q−3);\;c_{\rm top}\big)` says exactly:
> # **`z` has Jordan blocks ONLY of sizes `1, 2, q−1, q`** — equivalently, **no block of size in `[3, q−2]`**.

> ### **(i)** `z^q ∈ E'_k + m_U^{[q]}`, and **`z ≡ −e_1(U)`** modulo the defining relations. **So the operator whose Jordan type is sought is a LINEAR FORM — the sum of the variables.**

# 4 · `THEOREM C` — THE `Λ`-MODULE LEMMA *(`PROVED`, with proof)*

Let `Λ = K[z]/(z^q)`, let `K = Λ/(z)`, let `M = Λ^c ⊕ K^m`, and let `N ⊆ M` be a submodule.

> ### **THEOREM C.** *Write `z^{a_1}, …, z^{a_c}` for the elementary divisors of `N` inside the free part. Then*
> # `M / z^2 N \;\cong\; \bigoplus_i Λ/(z^{\min(a_i+2,\;q)}) \;\oplus\; K^m`,
> ### *i.e. the Jordan blocks of `z` on `M/z^2N` are* `\{a_i+2 : a_i ≤ q−3\} ∪ \{q\} ∪ \{1\}^m`.

**Proof.**

**Step 0 — `Λ` is a chain ring.** Its ideals are `(z^0) ⊋ (z^1) ⊋ ⋯ ⊋ (z^q) = 0`, **totally ordered by inclusion**. Hence `Λ` is a (special) principal ideal ring, and **every matrix over `Λ` admits a Smith normal form**; equivalently, for a submodule of a free `Λ`-module there is a basis of the free module adapted to it.

**Step 1 — the socle part splits off.** Since `z·K = 0`, we have `z^2 N ⊆ z^2 M = z^2 Λ^c ⊆ Λ^c`. Therefore
> ### `M/z^2N = (Λ^c/z^2N) ⊕ K^m`,
and the summand `K^m` contributes exactly `m` blocks of size `1`. *(This is the `\{1\}` in the statement.)*

**Step 2 — Smith form inside the free part.** By Step 0 there is a basis `f_1,…,f_c` of `Λ^c` with `N = \bigoplus_i (z^{a_i})f_i`, the `z^{a_i}` being the elementary divisors. Multiplying by `z^2`,
> ### `z^2 N = \bigoplus_i (z^{a_i+2}) f_i`.

**Step 3 — quotient, with saturation.** Hence `Λ^c/z^2N = \bigoplus_i Λ/(z^{a_i+2})`, and since `z^b = 0` in `Λ` as soon as `b ≥ q`, the `i`-th summand is `Λ/(z^{\min(a_i+2,\,q)})`.

**Step 4 — reading the two cases.** If `a_i ≤ q−3` then `a_i+2 ≤ q−1 < q`, and the block has size `a_i+2`. If `a_i ≥ q−2` then `a_i+2 ≥ q`, and the block has size `q`. Combining with Step 1 gives the stated list. ∎

⚠️ **The only hypothesis used is that `Λ` is a chain ring, which holds for `Λ = K[z]/(z^q)` over any field and any `q ≥ 1`.**
