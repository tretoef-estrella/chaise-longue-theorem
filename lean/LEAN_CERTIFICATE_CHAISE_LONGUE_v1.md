## 0. Verdict

For every odd `m ≥ 1` and every `k ≥ 0`, Lean 4 proves:

- the ring `R = Z[t_1, …, t_{2k+1}]/(t_1^m − 1, …, t_{2k+1}^m − 1)` modulo the ideal generated by the `(2k+1)!!` elements `ψ_J` of Degtyarev–Shimada is a **free abelian group of rank `m^{2k+1} − Q_k(m)`**;
- for **every field** `F`, `dim_F F[G]/(ψ_J) = m^{2k+1} − Q_k(m)`.

This is Main Theorem′ of the paper, stated there for `m ≥ 3` and `k ≥ 1`. It holds for every prime `p` at once, including every prime dividing `m`.

The whole proof compiles on the author's Mac. It contains no `sorry`, no `admit`, no `native_decide` and no added axiom. The final theorem depends only on the three standard axioms of Lean and Mathlib: `propext`, `Classical.choice` and `Quot.sound`.

**Main Theorem′ is not the Main Theorem.** The Main Theorem is Conjecture 1.2 itself: `H_{2k}(X; Z)/L(X)` is torsion free. It follows from Main Theorem′ by one topological result, [DS, Theorem 1.1(a)]: the torsion of `R/(ψ_J)` equals the torsion of `H_{2k}(X; Z)/L(X)`. That result rests on Pham's description of the homology of Fermat varieties and on the intersection numbers [DS, Theorem 2.2]. **It is not formalized; it is cited.** So:

> **Lean certifies the algebraic statement (Main Theorem′) completely. The Main Theorem follows from it by one cited topological result, the same one the paper cites.**

§1 states exactly what is proved. §2 states exactly what is not. §3–§8 describe how the result was obtained and how to check it.

## 1. The certified statement

### 1.1 The theorem, verbatim

Printed by Lean with `#check` (log `proyecto_lean/check_run29.log`):

```
@ColAssembly.mainTheorem' : ∀ {m : ℕ},
  Odd m →
    ∀ (k : ℕ),
      (Module.Free ℤ (RZ (2 * k + 1) m ⧸ IZ m k) ∧
          Module.finrank ℤ (RZ (2 * k + 1) m ⧸ IZ m k) = m ^ (2 * k + 1) - TheoremB.Qk k m) ∧
        ∀ (F : Type) [inst : Field F],
          Module.finrank F (ColSplit.GA F (2 * k + 1) m ⧸ ColUpper.IK F m k) = m ^ (2 * k + 1) - TheoremB.Qk k m
```

```
'ColAssembly.mainTheorem'' depends on axioms: [propext, Classical.choice, Quot.sound]
```

The integral part and the field part are also stated as two separate theorems. They are `ColAssembly.mainTheorem'_Z` and `ColAssembly.mainTheorem'_field`. The field version quantifies over fields in every universe; the combined theorem uses `F : Type`.

### 1.2 The definitions it uses, verbatim

These are all the definitions needed to read the statement. They are printed by `#print` in the same log.

```
def ColAssembly.idealZ : (d : ℕ) → ℕ → Ideal (MvPolynomial (Fin d) ℤ) :=
  fun d m => Ideal.span (Set.range fun i => MvPolynomial.X i ^ m - 1)

@[reducible] def ColAssembly.RZ : ℕ → ℕ → Type :=
  fun d m => MvPolynomial (Fin d) ℤ ⧸ idealZ d m

def ColAssembly.IZ : (m k : ℕ) → Ideal (RZ (2 * k + 1) m) :=
  fun m k => Ideal.span (Set.range fun J => (Ideal.Quotient.mk (idealZ (2 * k + 1) m)) (ColUpper.psiP ℤ m J))

def ColUpper.psiP : (R : Type u_1) → [CommRing R] → ℕ → {k : ℕ} → BallotBound.Matching k → MvPolynomial (Fin (2 * k + 1)) R :=
  fun R m {k} J =>
    (∏ a with a < ↑J a, (ColUpper.tP R k (↑J a) - 1)) *
      ∏ a with 0 < a ∧ a < ↑J a, ColSurv.phi m (ColUpper.tP R k a * ColUpper.tP R k (↑J a))

-- tP R k : Fin (2k+2) → MvPolynomial (Fin (2k+1)) R  is  Fin.cases 0 X  (t_0 := 0, t_a := X_{a−1} for a ≥ 1)

def ColSurv.phi : {A : Type u_2} → [Semiring A] → ℕ → A → A :=
  fun m u => ∑ s ∈ Finset.range m, u ^ s

def BallotBound.Matching : ℕ → Type :=
  fun k => { J // ∀ (x : Fin (2 * k + 2)), J x ≠ x ∧ J (J x) = x }

@[reducible] def ColSplit.GA : (F : Type u_1) → [Field F] → ℕ → ℕ → Type u_1 :=
  fun F d m => MvPolynomial (Fin d) F ⧸ ColSplit.gaIdeal F d m
  -- gaIdeal F d m = Ideal.span (Set.range fun i => X i ^ m - 1)

def ColUpper.IK : (K : Type u_1) → [Field K] → (m k : ℕ) → Ideal (ColSplit.GA K (2 * k + 1) m) :=
  fun K m k => Ideal.span (Set.range (ColUpper.psiG K m))
  -- psiG K m J is the same formula as psiP, read in GA K (2k+1) m

def TheoremB.Qk : ℕ → ℕ → ℕ :=
  fun k q =>
    ∑ b ∈ (Fintype.piFinset fun _ : Fin ((q - 1) / 2) => Finset.range (2 * k + 3)).filter
        (fun b => 2 * ∑ u, b u = 2 * k + 2),
      (2 * k + 2).factorial / ∏ u, (b u).factorial ^ 2
```

### 1.3 Faithfulness to the paper, line by line

The paper (v7, §1.1–§1.2 and §2) uses the notation of [DS] (arXiv:1405.4683v3).

| Paper | Lean | Agreement |
|---|---|---|
| `𝒥`: partitions of `{0, …, 2k+1}` into pairs, written `[[j_i, k_i]]` with `j_i < k_i`, `j_0 = 0`; `\|𝒥\| = (2k+1)!!` | `Matching k`: fixed-point-free involutions of `Fin (2k+2)` | The same objects. A pair `{a, J a}` with `a < J a` is `[j_i, k_i]`. |
| `R = Z[t_1, …, t_{2k+1}]/(t_i^m − 1)`, the group ring of `(Z/m)^{2k+1}` | `RZ (2k+1) m = ℤ[X_0, …, X_{2k}]/(X_i^m − 1)` | Identical, with 0-based indices: `t_a = X_{a−1}`. |
| `φ(u) = u^{m−1} + ⋯ + u + 1` | `phi m u = Σ_{s<m} u^s` | Identical. |
| `τ_J = Π_{i=0}^{k}(t_{k_i} − 1)` | `Π_{a < J a} (t_{J a} − 1)` | One factor per pair, for the larger index `k_i = J a`. |
| `ψ_J = τ_J · Π_{i=1}^{k} φ(t_{j_i} t_{k_i})` | `· Π_{0 < a < J a} φ(t_a · t_{J a})` | The pairs with `j_i ≠ 0`, i.e. `i ≥ 1`. |
| `t_0` never occurs | `tP R k 0 = 0` is a placeholder | It is never used: a factor `t_{J a} − 1` has `J a > a ≥ 0`, and a factor `φ(t_a t_{J a})` has `a > 0`. |
| the ideal `(ψ_J : J ∈ 𝒥)` of `R` | `IZ m k`: generated by the images of the `psiP ℤ m J` | Identical. |
| `F_p[G] = F_p[t]/(t_i^m − 1)` and `ψ̄_J` | `GA F (2k+1) m` and `IK F m k`, for **every** field `F` | Contains the paper's `F_p` as the case `F = ZMod p`. |
| `Q_k(q) = N!·[x^N] I_0(2x)^{(q−1)/2}`, `N = 2k+2`, `I_0(2x) = Σ x^{2b}/(b!)^2` | `Σ_{b : Fin((q−1)/2) → ℕ, 2Σb = 2k+2} (2k+2)!/Π(b_u!)^2` | The coefficient of `x^N` in `Π_u Σ_b x^{2b}/(b!)^2`, times `N!`. Each quotient is an integer: it is a multinomial coefficient with parts `b_u, b_u`. So the division in `ℕ` is exact. The bound `b_u ≤ 2k+2` is automatic, since `b_u ≤ k+1`. |
| «free abelian group of rank `r`» | `Module.Free ℤ M ∧ Module.finrank ℤ M = r` | Here `r ≥ 1` (see below), so `finrank = r` forces `M` finitely generated. The statement therefore says `M ≅ Z^r`. |
| `m^{2k+1} − Q_k(m)` | `m ^ (2k+1) - Qk k m` in `ℕ` (truncated subtraction) | Never truncates: the field part shows `Qk k m = dim_F I_F ≤ dim_F F[G] = m^{2k+1}`. In fact `Q_k(m) = \|Γ\| ≤ (m−1)^{2k+1} < m^{2k+1}`, so `r ≥ 1`. |

Three further checks tie `Qk` to its meaning:

- `TheoremB.card_closedTuples`: `Qk k q` is the number of closed tuples in `T^{2k+2}`, for every point set `T` with `|T| = q − 1`. This is Lemma 2.2 of the paper.
- `ColUpper.card_Gamma`: `Qk k m = |Γ_𝒥|`, the set of [DS, Definition 1.3], over a field with `m` distinct `m`-th roots of unity.
- `TheoremB/Checks.lean` evaluates `Qk` by `decide` at the paper's table: `Q_0(3) = 2`, `Q_0(5) = 4`, `Q_1(3) = 6`, `Q_1(5) = 36`, `Q_1(7) = 90`, `Q_1(9) = 168`, `Q_2(3) = 20`, `Q_2(5) = 400`, `Q_3(3) = 70`, and `Q_k(3) = C(2k+2, k+1)` for `k ≤ 4`.

**Generality.** The paper states Main Theorem′ for `m ≥ 3` and `k ≥ 1`. Lean proves it for every odd `m ≥ 1` and every `k ≥ 0`, and the field part for every field, not only `F_p`. The degenerate cases are consistent:

- at `m = 1`, `R = Z`, `Q_k(1) = 0`, and the rank is `1`;
- at `k = 0`, the statement is the paper's trivial case.

### 1.4 The other main theorems of the last piece

Also printed verbatim in `check_run29.log`, each with axioms `[propext, Classical.choice, Quot.sound]`:

- `ColAssembly.prop69` (Proposition 6.9, the colour reduction): for a field `F` of characteristic `p ≠ 2` containing `r` distinct `r`-th roots of unity, `r` odd, `m = p^v·r`: `dim_F I_F = Q_k(m)`.
- `ColAssembly.theorem_every_field`: for odd `m` and every field `F`, `rank_F(A) = Q_k(m)` and `dim_F I_F = Q_k(m)`. Here `A = ColUpper.intMatU m k` is the integer matrix of the `t^ν ψ_J` in the monomial basis.

## 2. What is not certified

1. **The topology.** Theorem 0(a), (c), (d) of the paper, i.e. [DS, Theorems 1.1(a) and 1.4], rest on Pham's theorem [Ph] and [DS, Theorem 2.2]. They identify the torsion of `R/(ψ_J)` with that of `H_{2k}(X; Z)/L(X)` and give the rank of `L(X)`. **Not formalized. Mathlib has no singular homology of complex Fermat varieties.**
2. **Hence the Main Theorem itself** — Conjecture 1.2 as a statement about homology — is certified only in its algebraic form.
3. **Not formalized, and not on the path of the proof:**
   - Corollary H (the integral Hodge conjecture);
   - Corollary W (partial Fermat varieties);
   - Theorem A of §8 and the counterexample of §9;
   - §10 and §11;
   - the verification record of §12.
   - *Formalized although not needed:* Theorems 5.9 and 5.9′ (equality over every field, freeness of `C/V_Λ` over `Z`) and the `q = 3` case of §4.
4. **Faithfulness is an audit, not a theorem.** Lean guarantees that the proof is correct for the statement as written. That the Lean statement says what the paper says is checked in §1.3 by the author's audit. **A reader should check §1.2–§1.3 independently: about a dozen short definitions.** This is the one place where trust in the author remains.
5. **Timing data.** Aristotle's own start and end times per task are shown on its web page but were not exported. The per-piece times in §6 are the download times of the result files: an upper bound for completion, not for Aristotle's work.

### 3.1 The chain of the final theorem

This is how `mainTheorem'` is proved in Lean. Every arrow is a Lean proof.

1. **Upper bound, every field** (piece 28, `finrank_IK_le`): `dim_F I_F ≤ Q_k(m)`.
   - `dim_F I_F = rank_F(A)` for an integer matrix `A` (part (i)).
   - `rank_F(A) ≤ rank_ℚ(A)` (piece 13).
   - `rank_ℚ(A) = rank_ℂ(A)`.
   - `rank_ℂ(A) = |Γ|` by evaluation at the `m`-th roots of unity: Lagrange interpolation and the Chinese remainder theorem (parts (ii)–(iii)).
   - `|Γ| = Q_k(m)` via closed tuples (Lemma 2.2, piece 10).

   This is [DS, Claim 4.3], re-proved without topology.
2. **Lower bound when `p | m`** (piece 29, `prop69_lower`).
   - `dim_F I = Σ_c dim_F π_c(I)` over the colourings `c` (Lemma 6.1).
   - Each term is `dim I_{c,1} · Π_ζ dim I_{c,ζ}` or `0` (Prop. 6.5, Lemma 6.3).
   - `dim I_{c,1} ≥ N_1(c)` (Lemma 6.6, via the §2 translation and Theorem B / Theorem 5.3).
   - `dim I_{c,ζ} ≥ N_ζ(c)` (Lemma 6.7, via Theorem C of §7).
   - `Σ_c N_1(c)Π_ζ N_ζ(c) = Q_k(m)` (Lemma 6.8).
3. **Every field** (`theorem_every_field`). `rank_F(A)` depends only on the prime field (`rank_map_algebraMap`).
   - Characteristic `0`: step 1 gives equality.
   - Characteristic `p ∤ m`: over `\overline{F_p}` the count `|Γ| = Q_k(m)` gives equality.
   - Characteristic `p | m`: `m = p^v r`, `r` odd, and over `\overline{F_p}` steps 1 and 2 give equality.
4. **Freeness over `Z`** (`mainTheorem'_Z`). `R` has the monomial `Z`-basis, and `I_Z` is the `Z`-span `L` of the rows of `A`. Since `rank_{F_p}(A) = rank_ℚ(A) = Q_k(m)` for every prime `p`, the lemma of piece 14 gives `Z^n/L ≅ Z^{n − Q_k(m)}`.

## 5. The procedure

For each of the 29 pieces:

1. **Write the piece from the paper.** A self-contained Markdown file with Setting, Statement, Proof and Checks. It names the earlier Lean results it may reuse and forbids changing any existing file or statement.
2. **Brute-force check before sending.** A Python program checks the statement in small cases, with at least one negative control where possible (a deliberately wrong variant that must fail). The numbers are in the table of §6.
3. **Send to Aristotle** (project `d1c5d0ac-9ffc-477b-ae34-0729a44d985c`), one task per piece.
4. **Download** the resulting project (a `.tar.gz`) and extract it into `run<N>/`.
5. **Diff** against the locally compiled project. Stop if any earlier `.lean` file changed. None ever did.
6. **Grep** the new folder for the forbidden constructs of §4.
7. **Build locally:** `lake build RequestProject.<Folder>.Main` under `/usr/bin/time -l`, log `build_run<N>.log`.
8. **Print** the main statements (`#check`), the definitions (`#print`) and the axioms (`#print axioms`), log `check_run<N>.log`.
9. **Audit faithfulness:** compare the printed statements and definitions with the piece and with the paper. Accept generalizations; stop on any weakening.
10. **Record** the run in the audit log `INFORME_ARISTOTLE_v1.md` and the state file `ESTADO_ARISTOTLE.md`.

**Stop conditions, fixed in advance:**
- any property NEGATED by Aristotle;
- a statement that is not faithful;
- a build failure;
- a `sorry` or an extra axiom;
- a change to an old file.

**None occurred.**

Twice (pieces 15 and 20) Aristotle's page showed a «review suggested» badge. Both times it accompanied Aristotle's own list of encoding choices (for example, bundling the Setting into a structure). The choices were reviewed and found sound. Several pieces were proved in a more general form than asked:
- unused hypotheses dropped (for example `m ≥ 3`, `k ≥ 1`, `v ≥ 1`);
- statements for any field or any ring;
- a different proof of the same statement (for example Mathlib's combinatorial Nullstellensatz in place of the Chinese remainder theorem in piece 2).

Each is noted in the audit log.

## 9. What this certificate claims, in one paragraph

A computer proof assistant, Lean 4 with the Mathlib library, has checked a complete proof of the following statement, with no gap and no axiom beyond the three standard ones:

> For every odd `m` and every `k ≥ 0`, the quotient of the integral group ring `Z[(Z/m)^{2k+1}]` by the ideal generated by the Degtyarev–Shimada elements `ψ_J` is a free abelian group of rank `m^{2k+1} − Q_k(m)`, and over every field the corresponding quotient has that dimension.

By [DS, Theorem 1.1(a)] (Pham's theorem and the intersection numbers of [DS, Theorem 2.2], cited and not formalized), this is equivalent to Conjecture 1.2 of Degtyarev and Shimada for the Fermat varieties of odd degree `m` in even dimension `2k`.

The proofs in Lean were written by the AI system Aristotle (Harmonic) from pieces written by the author. The author's audit, assisted by Claude (Anthropic), checked that the statements match the paper, and compiled and re-checked everything on his own machine.
