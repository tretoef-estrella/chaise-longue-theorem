# The bipartite setting (§7.1–§7.2 of the paper): peeling with the box q, shapes, pairs of partitions, tight patterns, and the roots

This file uses, unchanged: `q_peeling_lemma.md` (the ring `C_m` with box `q − 1`, its slices `W_j`, and parts (i)–(iv) of its Lemma), `q_chain_lemma.md` (partitions, `S_t`, weak dominance `≼`) and `q_P3_identities.md` (the Vandermonde `Δ(B) = Π_{c<c'}(y_{b_{c'}} − y_{b_c})`, column lengths `λ'_c`).

## Setting

Let `F` be a field, `q ≥ 3` odd, and `Ω` a finite set with `|Ω| = q`. For `α, β ≥ 0`:

**The ring.** `R_{α,β} := F[x_1, …, x_α, z_1, …, z_β]/(x_i^q, z_l^q)`. It is the ring `C_{α+β}` of `q_peeling_lemma.md` **with `q + 1` in place of `q`** (box exponent `(q + 1) − 1 = q`), with the variables `y_1, …, y_α` named `x_1, …, x_α` and `y_{α+1}, …, y_{α+β}` named `z_1, …, z_β`. Peeling `w := x_1` is peeling `y_1`.

**Shapes.** A point is `(ξ, η) ∈ Ω^α × Ω^β`. For `u ∈ Ω` let `X(u) := #{i : ξ_i = u}` and `Y(u) := #{l : η_l = u}`. The **shape** of `(ξ, η)` is `λ(ξ, η) := (λ_+, λ_−)`, where `λ_+` is the partition whose parts are the numbers `X(u) − Y(u)` for the `u` with `X(u) > Y(u)`, and `λ_−` the partition whose parts are the numbers `Y(u) − X(u)` for the `u` with `Y(u) > X(u)`.

**Pairs of partitions.** `BPar_q(α, β)` is the set of pairs `(λ_+, λ_−)` of partitions with `|λ_+| − |λ_−| = α − β` (in `ℤ`), `|λ_+| + |λ_−| ≤ α + β` and `ℓ(λ_+) + ℓ(λ_−) ≤ q`. The order is the product order: `(λ_+, λ_−) ≼ (μ_+, μ_−)` iff `λ_+ ≼ μ_+` and `λ_− ≼ μ_−`. A **down-set of `BPar_q(α, β)`** is a set `Λ ⊆ BPar_q(α, β)` such that `λ ∈ BPar_q(α, β)`, `λ ≼ μ` and `μ ∈ Λ` imply `λ ∈ Λ`. For such `Λ`, `Z_Λ := {(ξ, η) ∈ Ω^α × Ω^β : λ(ξ, η) ∈ Λ}`.

**Tight patterns.** A tight pattern of `λ = (λ_+, λ_−) ∈ BPar_q(α, β)` consists of
- a set `P` of `α − |λ_+|` pairs `(i, l) ∈ [α] × [β]`, with the `i` pairwise distinct and the `l` pairwise distinct (then also `β − |λ_−| = α − |λ_+|` pairs);
- blocks `B^+_1, …, B^+_{λ_{+,1}}` partitioning `[α] ∖ {i : (i, l) ∈ P}`, with `|B^+_c| = (λ_+)'_c`;
- blocks `B^−_1, …, B^−_{λ_{−,1}}` partitioning `[β] ∖ {l : (i, l) ∈ P}`, with `|B^−_c| = (λ_−)'_c`.

Its **product** is `Π_{(i,l) ∈ P} (x_i − z_l)^{q−1} · Π_c Δ(x_{B^+_c}) · Π_c Δ(z_{B^−_c}) ∈ R_{α,β}`, where `Δ(x_B) := Π_{c<c' in B}(x_{c'} − x_c)` (and likewise for `z`). `V_Λ ⊆ R_{α,β}` is the ideal generated by the products of all tight patterns of all elements of `Λ`.

**The root ideals and counts.**
- `I^{bal}_a ⊆ R_{a,a}` is the ideal generated by `Π_{i=1}^{a} (x_i − z_{σ(i)})^{q−1}`, `σ` a permutation of `[a]`.
- `I^{ph}_a ⊆ R_{a+1,a}` is the ideal generated by `Π_{i ≠ i_0} (x_i − z_{σ(i)})^{q−1}`, for `i_0 ∈ [a+1]` and `σ : [a+1] ∖ {i_0} → [a]` a bijection.
- `N_{bal}(a, q) := #{(ξ, η) ∈ Ω^a × Ω^a : X = Y}` (the multisets of values of `ξ` and `η` are equal).
- `N_{ph}(a, q) := #{(ξ, η) ∈ Ω^{a+1} × Ω^a : Y(u) ≤ X(u) for every u}`.

## Lemma 7.1 (peeling with the box q)

For `α ≥ 1`, `V` an ideal of `R_{α,β}` and `0 ≤ j ≤ q − 1`, let `W_j(V) ⊆ R_{α−1,β}` be the slice of `q_peeling_lemma.md` (with `q + 1` in place of `q`, peeling `w = x_1`). Then: (i) `W_j(V)` is an ideal; (ii) `W_j(V) ⊆ W_{j+1}(V)` for `0 ≤ j < q − 1`; (iii) `dim V = Σ_{j=0}^{q−1} dim W_j(V)`; (iv) for `Z ⊆ Ω^α × Ω^β`, with fibres `F(M') := {u ∈ Ω : (u, M') ∈ Z}` over the tails `M'` (all coordinates but `ξ_1`) and `Z_{>i} := {M' : |F(M')| > i}`: `|Z| = Σ_{i=0}^{q−1} |Z_{>i}|`.

*Proof.* Parts (i)–(iv) of the Lemma of `q_peeling_lemma.md` with `q + 1` in place of `q` (so `|Ω| = (q + 1) − 1`), on `α + β` variables, peeling the first one. ∎

## Lemma 7.2 (the roots)

**(0)** For every point, `λ(ξ, η) ∈ BPar_q(α, β)`.

**(i)** `{(∅, ∅)}` is a down-set of `BPar_q(a, a)`; `V_{{(∅,∅)}} = I^{bal}_a`; and `|Z_{{(∅,∅)}}| = N_{bal}(a, q)`.

**(ii)** `{((1), ∅)}` is a down-set of `BPar_q(a + 1, a)`; `V_{{((1),∅)}} = I^{ph}_a`; and `|Z_{{((1),∅)}}| = N_{ph}(a, q)`.

**(iii)** `N_{ph}(a, q) = N_{bal}(a + 1, q)`.

## Proofs

(0) `|λ_+| − |λ_−| = Σ_u (X(u) − Y(u)) = α − β`; `|λ_+| + |λ_−| = Σ_u |X(u) − Y(u)| ≤ Σ_u (X(u) + Y(u)) = α + β`; the parts of `λ_+` and of `λ_−` come from disjoint sets of values of `Ω`, so `ℓ(λ_+) + ℓ(λ_−) ≤ |Ω| = q`.

(i) If `(λ_+, λ_−) ≼ (∅, ∅)` then `S_t(λ_±) ≤ 0` for all `t ≥ 1`, so `λ_± = ∅`; and `(∅, ∅) ∈ BPar_q(a, a)`. A tight pattern of `(∅, ∅)` on `([a], [a])` has `a` pairs and no blocks: a bijection `σ : [a] → [a]`, with product `Π_i (x_i − z_{σ(i)})^{q−1}`; so the generators of `V_{{(∅,∅)}}` and of `I^{bal}_a` are the same. The shape of `(ξ, η)` is `(∅, ∅)` iff `X(u) = Y(u)` for all `u`, iff the multisets are equal.

(ii) In `BPar_q(a + 1, a)`, `|λ_+| = |λ_−| + 1`. If `(λ_+, λ_−) ≼ ((1), ∅)` then `λ_− = ∅`, so `|λ_+| = 1` and `λ_+ = (1)`; and `((1), ∅) ∈ BPar_q(a+1, a)` since `1 ≤ q`. A tight pattern of `((1), ∅)` has `a` pairs, i.e. a bijection `σ` from `[a+1] ∖ {i_0}` to `[a]`, and one `x`-block `{i_0}` of size `1` (`Δ = 1`); so its product is a generator of `I^{ph}_a`, and every generator arises. The shape is `((1), ∅)` iff `X(u) − Y(u) ∈ {0, 1}` for all `u` with exactly one `1` (as `Σ (X − Y) = 1`), iff `Y(u) ≤ X(u)` for all `u` (then `Σ_u (X(u) − Y(u)) = 1` forces a single difference `1`).

(iii) If `Y ≤ X` with `|X| = a + 1`, `|Y| = a`, there is exactly one `u^*` with `X(u^*) = Y(u^*) + 1`; appending `u^*` to `η` gives a balanced point of `Ω^{a+1} × Ω^{a+1}`. Conversely, deleting the last coordinate `η_{a+1}` of a balanced point gives `Y ≤ X`. The two maps are mutually inverse. ∎

## Checks

- Enumeration: `N_{bal}(a, 3) = 3, 15, 93, 639` for `a = 1, …, 4` (and the formula `Σ_{c_1+⋯+c_q = a} (a!/Π c_u!)^2` gives `3, 15, 93, 639, 4653` for `a = 1..5`); `N_{bal}(2, q) = 15, 45, 91, 153, 231` for `q = 3, 5, 7, 9, 11` — the values printed in §7.2 of the paper.
- `N_{ph}(a, q) = N_{bal}(a + 1, q)` for `q ∈ {3, 5, 7}`, `a ∈ {0, 1, 2}`.
- Part (0) and the two shape characterizations used in (i) and (ii), at every point of `Ω^α × Ω^β` for `q ∈ {3, 5}`, `α, β ≤ 3`: 25 936 points, 0 failures.
