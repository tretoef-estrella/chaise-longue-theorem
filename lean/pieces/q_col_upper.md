# The upper bound (6.1): the Chinese-remainder count of [DS, Claim 4.3] (Theorem 0(b) and Appendix B, Step 6 of the paper)

This file uses, unchanged:
- `q_col_splitting.md`: the ring `F[G] := F[t_1, …, t_d]/(t_1^m − 1, …, t_d^m − 1)` over a field (here written `K[G]` for a field `K` and any `m ≥ 1`);
- `q_col_survivors.md`: `k`, `d = 2k + 1`, `V = {0, …, 2k+1}`, matchings `J` of `V` (fixed-point-free involutions), `φ(u) := u^{m−1} + ⋯ + u + 1`, and the formula for `ψ_J`;
- `q_P1_fibres.md`, `q_theorem_B_lower.md`: point sets `T` with a fixed-point-free involution and `|T| = 2h`, closed tuples, `Q_k(q)`, and Theorem (ii) of `q_theorem_B_lower.md`: for every point set `T` with `|T| = 2h`, `h = (q − 1)/2`, the number of closed tuples in `T^{2k+2}` is `Q_k(q)`;
- `q_every_field.md`: the rank `rank_K(A)` of an integer matrix over a field `K`, and its part (ii): `rank_K(A) ≤ rank_ℚ(A)` for every field, with equality if `char K = 0`.

## Setting

`K` is any field, `m ≥ 1`, `k ≥ 0`, `d = 2k + 1`. In `K[G]` write `t_a` for the class of the `a`-th variable (`a = 1, …, d`); `t_0` is a dummy value that never occurs. For a matching `J` of `V`,

`ψ_J := Π_{a < J(a)} (t_{J(a)} − 1) · Π_{0 < a < J(a)} φ(t_a t_{J(a)}) ∈ K[G]`

(the same formula as in `q_col_survivors.md`, now for any field and any `m`), and

`I_K := (ψ_J : J a matching of V) ⊆ K[G]`.

**Roots of unity.** A set `μ_m ⊆ K` of *`m` distinct `m`-th roots of unity* is a finite set with `|μ_m| = m` and `X^m − 1 = Π_{ξ ∈ μ_m} (X − ξ)` in `K[X]`. For `a ∈ μ_m^d`, `ev_a : K[G] → K` is the `K`-algebra map `t_i ↦ a_i` (well defined, as `a_i^m = 1`). Put

`Γ := {a ∈ μ_m^d : ev_a(ψ_J) ≠ 0 for some matching J}`.

## Theorem (the upper bound)

**(0) (the monomial basis)** For every field `K` and `m ≥ 1`, the classes of the monomials `t^ν = t_1^{ν_1} ⋯ t_d^{ν_d}`, `0 ≤ ν_i ≤ m − 1`, form a `K`-basis of `K[G]`; so `dim_K K[G] = m^d`.

**(i) (an integer matrix)** There is an integer matrix `A`, depending only on `m` and `k`, such that `dim_K I_K = rank_K(A)` for every field `K`. (The rows are indexed by the pairs `(ν, J)`, the columns by the exponents `μ ∈ {0, …, m−1}^d`, and the entry is the coefficient of `t^μ` in `t^ν ψ_J` written in the basis of (0); it is the image of an integer computed from `ψ_J` over `Z`, the same for every `K`.)

**(ii) (the count)** If `K` contains a set `μ_m` of `m` distinct `m`-th roots of unity and `m ≠ 0` in `K`, then `dim_K I_K = |Γ|`.

**(iii) (the points are closed tuples)** If moreover `m` is odd, then `|Γ| = Q_k(m)`.

**(iv) (the upper bound (6.1))** Let `m ≥ 3` be odd. For every field `F`,

`dim_F I_F ≤ Q_k(m)`,

and equality holds if `char F = 0` and `F` contains `m` distinct `m`-th roots of unity; in particular `rank_ℚ(A) = Q_k(m)`.

## Proof

(0) The monomials `t^ν` with `ν ∈ N^d` span `K[G]`, and `t_i^m = 1` reduces every exponent mod `m`; so the `t^ν` with `ν_i < m` span. They are independent: a relation `Σ_ν c_ν t^ν = 0` means `Σ_ν c_ν X^ν ∈ (X_i^m − 1)`; the polynomials `X_i^m − 1` form a Gröbner basis (their leading monomials are coprime), so the remainder `Σ_ν c_ν X^ν`, whose exponents are all `< m`, is `0`. (Any other proof is fine: e.g. `K[G] ≅ ⊗_i K[t]/(t^m − 1)`.)

(i) `I_K` is the `K`-span of the elements `t^ν ψ_J` (`ν` as in (0), `J` a matching), since `K[G]` is spanned by the `t^ν`. Let `ψ_J^Z ∈ Z[X_1, …, X_d]` be the polynomial given by the same formula (with `X_a` for `t_a`); its image in `K[G]` is `ψ_J`. Write `X^ν ψ_J^Z = Σ_e b_e X^e` and put `A_{(ν,J), μ} := Σ_{e : e_i ≡ μ_i (mod m) ∀i} b_e ∈ Z`. In `K[G]`, `t^e = t^μ` whenever `e ≡ μ (mod m)`, so `t^ν ψ_J = Σ_μ (A_{(ν,J),μ} · 1_K) t^μ`: in the basis of (0) the row `(ν, J)` of `A`, read in `K`, is the coordinate vector of `t^ν ψ_J`. So `dim_K I_K` is the rank of `A` read in `K`.

(ii) *Evaluation.* The map `E : K[G] → K^{μ_m^d}`, `f ↦ (ev_a(f))_a`, is a `K`-algebra map. It is surjective: for `ξ ∈ μ_m` let `L_ξ(X) := Π_{η ∈ μ_m, η ≠ ξ} (X − η)/(ξ − η)` (the `η` are distinct); then `Π_i L_{a_i}(t_i)` maps to the indicator of `a`. By (0), `dim K[G] = m^d = dim K^{μ_m^d}`, so `E` is an isomorphism. *The ideal.* In the product ring `K^X` (`X` finite), the ideal generated by a family `(f_j)` is `{g : g(x) = 0 whenever f_j(x) = 0 for every j}`, of dimension `#{x : f_j(x) ≠ 0 for some j}` (it contains the indicator of each such `x`, since `1_x = f_j(x)^{−1} 1_x · f_j`). Hence `dim_K I_K = dim_K E(I_K) = |Γ|`.

(iii) *The values of `ψ_J`.* For `b ∈ μ_m`: `φ(1) = m ≠ 0`, and for `b ≠ 1`, `(b − 1) φ(b) = b^m − 1 = 0`, so `φ(b) = 0`. `μ_m` is closed under products and inverses (it is the set of roots of `X^m − 1`). Hence, for `a ∈ μ_m^d`: `ev_a(ψ_J) ≠ 0` iff `a_{J(x)} ≠ 1` for every pair `x < J(x)` of `J`, and `a_x a_{J(x)} = 1` for every pair with `0 < x < J(x)`.

*A point set.* `T := μ_m ∖ {1}` with `u ↦ u^{−1}` is a point set with a fixed-point-free involution and `|T| = m − 1 = 2h`, `h = (m − 1)/2`: if `u^{−1} = u` then `u^2 = 1 = u^m` with `m` odd, so `u = u^{m} · (u^{2})^{−(m−1)/2} = 1`.

*The bijection.* For `a ∈ Γ` put `a_0 := (a_1 ⋯ a_d)^{−1}` and `g(a) := (a_0, a_1, …, a_d)`. If `ev_a(ψ_J) ≠ 0`, the pairs of `J` avoiding `0` have `a_x a_{J(x)} = 1`, so `a_0 = a_b^{−1}` where `{0, b}` is the pair of `J` containing `0`; so every `a_i` (`i = 0, …, d`) lies in `T`, and `J` pairs the entries of `g(a)` into inverse pairs, so `g(a)` is a closed tuple of `T^{2k+2}`. Conversely let `g ∈ T^{2k+2}` be closed. Its product is `1` (the counts of `u` and `u^{−1}` agree, and `u ≠ u^{−1}`), so `g_0 = (g_1 ⋯ g_d)^{−1}`. There is a matching `J` of `V` with `g_{J(x)} = g_x^{−1}` for every `x` (for each pair `{u, u^{−1}}` of values, match the positions with value `u` bijectively to those with value `u^{−1}`); then `ev_{(g_1,…,g_d)}(ψ_J) ≠ 0` by the criterion above. The two maps are inverse to each other. So `|Γ|` is the number of closed tuples in `T^{2k+2}`, which is `Q_k(m)` by Theorem (ii) of `q_theorem_B_lower.md` (with `q := m`, `h := (m − 1)/2`).

(iv) The complex numbers contain `m` distinct `m`-th roots of unity (the `m`-th roots of `1` in `C`, i.e. the powers of `e^{2πi/m}`, with `X^m − 1 = Π (X − ζ)`), and `m ≠ 0` in `C`. By (i), (ii), (iii) and part (ii) of `q_every_field.md`: `dim_F I_F = rank_F(A) ≤ rank_Q(A) = rank_C(A) = dim_C I_C = |Γ| = Q_k(m)`. If `char F = 0` and `F` contains `m` distinct `m`-th roots of unity (then `m ≠ 0` in `F`), (ii) and (iii) give equality directly. ∎

## Checks

- Exact rank of `I_K` (all `t^ν ψ_J` as vectors in the basis of (0)) at `(m, k) = (3, 1), (5, 1), (7, 1), (9, 1), (3, 2)`: over `F_p` for every prime `p | m` the rank is `≤ Q_k(m)` (in fact equal: `6, 36, 90, 168, 20`), and over `F_P` for a prime `P ≡ 1 (mod m)` (`P = 7, 11, 29, 19, 7`), which contains `m` distinct `m`-th roots of unity, the rank equals `|Γ|` computed by evaluating every `ψ_J` at every point of `μ_m^d`, and both equal `Q_k(m)`. At `(m, k) = (15, 1)`, `|Γ| = 546 = Q_1(15)` by evaluation over `F_31`. 6 checks, 0 failures.
- Negative control: with `t_b + 1` in place of `t_b − 1` in `ψ_J`, the rank over `F_P` is `19, 61, 127, 217, 141` instead of `Q_k(m)` (5 of 5 differ).
