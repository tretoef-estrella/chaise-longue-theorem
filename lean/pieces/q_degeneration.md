# Degeneration: the dimension of an ideal of C_m is at most the size of the support

This file uses the ring `C_m` of `q_peeling_lemma.md`.

## Setting

Let `F` be a field, `q ≥ 3`, `m ≥ 0`, `S := F[y_1, …, y_m]` and `C_m := S/(y_1^{q−1}, …, y_m^{q−1})`.

Let `T ⊆ F` be a set of `q − 1` elements with `Π_{u∈T} (y − u) = y^{q−1} − 1` in `F[y]` (i.e. `T` is the set of `(q−1)`-th roots of unity of `F`, and there are `q − 1` of them).

**Top-degree forms.** For `f ∈ S`, `f ≠ 0`, of total degree `d`, let `f^{top}` be its homogeneous component of degree `d`. For an ideal `I ⊆ S`, `gr(I)` is the set of `0` and of all `f^{top}`, `f ∈ I ∖ {0}`, together with their sums; equivalently its degree-`d` part is `{0} ∪ {f^{top} : f ∈ I, deg f = d}`, which is a subspace. `gr(I)` is a homogeneous ideal.

## Lemma

**(i)** If `f_1, …, f_s ∈ I` are nonzero, then `(f_1^{top}, …, f_s^{top}) ⊆ gr(I)`.

**(ii)** If `dim_F S/I < ∞`, then `dim_F S/gr(I) = dim_F S/I`.

## Proposition (degeneration)

Let `g_1, …, g_s ∈ S` be homogeneous polynomials, and let

`Σ := {M ∈ T^m : g_i(M) ≠ 0 for some i}`   (the union of the supports of the `g_i` on `T^m`).

Let `V ⊆ C_m` be the ideal generated by the images of `g_1, …, g_s`. Then

`dim_F V ≤ |Σ|`.

## Proof

(i) Each `f_j ∈ I`, so `f_j^{top} ∈ gr(I)`, and `gr(I)` is an ideal.

(ii) Filter `S` by degree: `S_{≤d} := {f : deg f ≤ d}`. Then `A := S/I` is filtered by `A_{≤d} := S_{≤d}/(I ∩ S_{≤d})` (images), and since `dim A < ∞` the filtration is exhaustive and stabilizes, so `dim A = Σ_d dim(A_{≤d}/A_{≤d−1})`. The map `S_d → A_{≤d}/A_{≤d−1}` (homogeneous forms of degree `d`) is onto, and its kernel is `gr(I)_d`: a form `φ` of degree `d` maps to `0` iff `φ = f − r` with `f ∈ I` and `deg r < d`, iff `φ = 0` or `φ = f^{top}` for some `f ∈ I` of degree `d`. Hence `dim(A_{≤d}/A_{≤d−1}) = dim S_d/gr(I)_d`, and summing over `d`, `dim S/I = dim S/gr(I)` (the sum on the right is `dim S/gr(I)` because `gr(I)` is homogeneous). (Equivalently: a degree-compatible monomial order gives `I` and `gr(I)` the same leading monomials, and Macaulay's basis theorem.)

*Proposition.* Put `I := (g_1, …, g_s) + (y_1^{q−1} − 1, …, y_m^{q−1} − 1) ⊆ S`.

1. *Chinese remainder.* Since `y^{q−1} − 1 = Π_{u∈T}(y − u)` with distinct roots, `S/(y_1^{q−1} − 1, …, y_m^{q−1} − 1)` is isomorphic, by evaluation, to the ring `F^{T^m}` of functions `T^m → F`.
2. *Ideals of a product of fields.* In `F^{T^m}`, the ideal generated by functions `φ_1, …, φ_s` is the set of functions vanishing outside `⋃_i supp(φ_i)` (use the idempotents `e_M`). So `S/I ≅ F^{T^m}/(g_i|_{T^m}) ≅ F^{T^m ∖ Σ}` and `dim_F S/I = |T^m ∖ Σ| = (q − 1)^m − |Σ|`.
3. *Top forms.* Each nonzero `g_i` is homogeneous, so `g_i^{top} = g_i`; and `(y_j^{q−1} − 1)^{top} = y_j^{q−1}`. By (i), `I' := (g_1, …, g_s) + (y_1^{q−1}, …, y_m^{q−1}) ⊆ gr(I)`.
4. *Count.* `S/I` is finite-dimensional, so by (ii) and 3,

`dim_F S/I' ≥ dim_F S/gr(I) = dim_F S/I = (q − 1)^m − |Σ|`.

Since `S/I' ≅ C_m/V` and `dim C_m = (q − 1)^m`, this gives `dim_F V ≤ |Σ|`. ∎

## Checks

- Random test over `F_101` (where `T` = the `(q−1)`-th roots of unity, `q ∈ {3, 5, 11}`, `(q−1)^m ≤ 1400`), 1–3 random homogeneous generators: 135 cases, `dim V ≤ |Σ|` in all.
- Homogeneity is needed: for `q` odd and `m = 1`, `g = 1 + y_1` is a unit in `C_1`, so `dim V = q − 1`, while `Σ = T ∖ {−1}` has `q − 2` elements.
