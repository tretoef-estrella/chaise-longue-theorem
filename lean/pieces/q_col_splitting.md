# The splitting of the group algebra by colourings (§6.1 of the paper, Lemma 6.1)

This file is self-contained.

## Setting

Let `F` be a field of characteristic `p` (a prime), `q = p^v` with `v ≥ 1`, and `r ≥ 1`. Let `μ ⊆ F` be a finite set with `|μ| = r` and

`X^r − 1 = Π_{ζ ∈ μ} (X − ζ)`   in `F[X]`

(so `μ` is the set of the `r` distinct `r`-th roots of unity of `F`; this forces `r ≠ 0` in `F`). Put `m := q·r`, and let `d ≥ 0` (in the paper `d = n + 1`). Let `S := F[t_1, …, t_d]` and

`F[G] := S/(t_1^m − 1, …, t_d^m − 1)`.

For a colouring `c = (c_1, …, c_d) ∈ μ^d` put

`J_c := ((t_1 − c_1)^q, …, (t_d − c_d)^q) ⊆ S`,   `R_c := S/J_c`.

## Lemma 6.1 (splitting)

**(0)** For every `ζ ∈ μ`: `X^m − 1 = Π_{ξ ∈ μ} (X − ξ)^q` in `F[X]`, and hence `t_i^m − 1 ∈ J_c` for every `c ∈ μ^d` and every `i`. So the quotient map `S → R_c` induces an `F`-algebra map `π_c : F[G] → R_c`, which is surjective.

**(i)** The product map `π := (π_c)_{c ∈ μ^d} : F[G] → Π_{c ∈ μ^d} R_c` is an isomorphism of `F`-algebras.

**(ii)** For every ideal `I'` of `F[G]`: `dim_F I' = Σ_{c ∈ μ^d} dim_F π_c(I')`, where `π_c(I')` is the image of `I'` (an ideal of `R_c`, since `π_c` is surjective).

**(iii)** If `I'` is generated by a set `E ⊆ F[G]`, then `π_c(I')` is the ideal of `R_c` generated by `π_c(E)`.

## Proof

(0) In characteristic `p`, the Frobenius map `f ↦ f^q` of `F[X]` is a ring homomorphism, so `(X^r − 1)^q = X^{rq} − 1 = X^m − 1`. Hence `X^m − 1 = (Π_ξ (X − ξ))^q = Π_ξ (X − ξ)^q`. Substituting `X = t_i`, the factor `(t_i − c_i)^q` divides `t_i^m − 1` in `S`, so `t_i^m − 1 ∈ J_c`.

(i) *Dimensions.* `F[G]` has the `F`-basis of monomials `t^a`, `0 ≤ a_i ≤ m − 1`, so `dim_F F[G] = m^d`. `R_c` has the `F`-basis of the products `Π_i (t_i − c_i)^{b_i}`, `0 ≤ b_i ≤ q − 1` (after the change of variables `s_i := t_i − c_i`, `R_c = F[s_1, …, s_d]/(s_1^q, …, s_d^q)`), so `dim_F R_c = q^d`, and `dim_F Π_c R_c = r^d·q^d = m^d`.

*Surjectivity.* For `c ≠ c'` in `μ^d`, the ideals `J_c` and `J_{c'}` are comaximal: pick `i` with `c_i ≠ c'_i`; the one-variable polynomials `(X − c_i)^q` and `(X − c'_i)^q` are coprime in `F[X]` (they have no common root), so `a(X)(X − c_i)^q + b(X)(X − c'_i)^q = 1` for some `a, b`, and substituting `X = t_i` gives `1 ∈ J_c + J_{c'}`. By the Chinese remainder theorem for the finite family of pairwise comaximal ideals `(J_c)_{c ∈ μ^d}`, the map `S → Π_c S/J_c` is surjective. It factors as `S → F[G] →^π Π_c R_c` by (0), so `π` is surjective.

A surjective linear map between `F`-spaces of the same finite dimension `m^d` is bijective, so `π` is an isomorphism of `F`-algebras.

(ii) Let `e_c ∈ Π_{c'} R_{c'}` be the idempotent with component `1` at `c` and `0` elsewhere. `π(I')` is an ideal of the product, and for `y ∈ π(I')` each `e_c y ∈ π(I')`; hence `π(I') = Π_c pr_c(π(I'))`, where `pr_c` is the projection. Since `pr_c ∘ π = π_c`, this is `Π_c π_c(I')`. As `π` is an injective linear map, `dim_F I' = dim_F π(I') = Σ_c dim_F π_c(I')`.

(iii) `π_c` is a surjective ring homomorphism, so the image of the ideal generated by `E` is the ideal generated by `π_c(E)`. ∎

## Checks

- `F = F_p`, with `μ ⊆ F_p^×` the `r`-th roots of unity (`r | p − 1`): `(p, q, r) ∈ {(3,3,2), (5,5,2), (7,7,3), (7,7,2), (3,9,2), (5,5,4)}`, `d ∈ {1, 2}`: the matrix of `π` in the monomial bases has full rank `m^d` (so (i) holds), and `dim I' = Σ_c dim π_c(I')` for three random ideals `I'` in each cell; 12 cells, 0 failures.
- Negative control (`q` not a power of `p`): for `(p, q, r) ∈ {(5,3,2), (7,3,2), (7,5,3)}`, `t^m − 1 ∉ J_c` for every colour `c`, so `π_c` is not even defined — the Frobenius step (0) is needed.
