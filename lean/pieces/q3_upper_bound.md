# An upper bound for the same ideal, and equality

This file continues `q3_ballot_lower_bound.md` and uses its **Setting** unchanged: `F` a field, `k ≥ 0`, `n' := 2k+1`, `C := F[y_1, …, y_{n'}]/(y_1^2, …, y_{n'}^2)`, `𝒥` the perfect matchings of `{0, 1, …, n'}`, `D_J := ∏_{ {a,b} ∈ J, a < b, 0 ∉ {a,b} } (y_b − y_a)`, and `V ⊆ C` the ideal generated by all `D_J`.

## Theorem (upper bound)

If `char F ≠ 2`, then for every `k ≥ 0`,

`dim_F V ≤ binomial(2k + 2, k + 1)`.

## Corollary (equality)

If `char F ≠ 2`, then `dim_F V = binomial(2k + 2, k + 1)` for every `k ≥ 0` (combine with the lower bound of `q3_ballot_lower_bound.md`, which holds for every field).

## Proof of the Theorem

Write `S := F[y_1, …, y_{n'}]` and let `g_J ∈ S` be the polynomial `∏_{(a,b)} (y_b − y_a)` (same product as `D_J`, before passing to `C`). Each `g_J` is homogeneous of degree `k`.

**(i) Evaluation on `{1, −1}`.** Put `T := {1, −1} ⊆ F`; it has two elements because `char F ≠ 2`. For `a, b ∈ T`, `b − a ≠ 0` iff `b = −a`. Hence, for a point `z ∈ T^{n'}`, `g_J(z) ≠ 0` iff every pair `(a, b)` of `J` not containing `0` satisfies `z_b = −z_a`.

**(ii) The support.** Let `Σ := {z ∈ T^{n'} : g_J(z) ≠ 0 for some J ∈ 𝒥}`. If `g_J(z) ≠ 0`, the `k` pairs of `J` not containing `0` cover `n' − 1 = 2k` coordinates, each pair with one entry `1` and one entry `−1`; the remaining coordinate is `1` or `−1`. So the number of coordinates of `z` equal to `1` is `k` or `k + 1`. Hence

`|Σ| ≤ binomial(2k+1, k) + binomial(2k+1, k+1) = binomial(2k+2, k+1)`.

**(iii) The ring of functions.** Let `I := (g_J : J ∈ 𝒥) + (y_1^2 − 1, …, y_{n'}^2 − 1) ⊆ S`. Since `y^2 − 1 = (y − 1)(y + 1)` with `1 ≠ −1`, the Chinese remainder theorem gives `S/(y_i^2 − 1 : i) ≅ F^{T^{n'}}`, the ring of `F`-valued functions on `T^{n'}` (a finite product of copies of `F`). In a finite product of fields, the ideal generated by a family of functions is the set of functions vanishing outside the union of their supports. So `I/(y_i^2 − 1)` is the set of functions vanishing on `T^{n'} ∖ Σ`, and

`dim_F S/I = 2^{n'} − |Σ|`.

**(iv) Top-degree forms.** For an ideal `I ⊆ S` let `gr(I)` be the ideal spanned by the top-degree homogeneous components of the non-zero elements of `I`. Two standard facts:
- (a) if `I` is generated by `f_1, …, f_s`, then `gr(I)` contains the top-degree components `f_1^{top}, …, f_s^{top}`;
- (b) if `dim_F S/I < ∞`, then `dim_F S/gr(I) = dim_F S/I` (fix a degree-compatible monomial order: `I` and `gr(I)` have the same leading monomials, and the standard monomials are a basis of both quotients by Macaulay's basis theorem).

The top-degree component of `g_J` is `g_J` (it is homogeneous), and that of `y_i^2 − 1` is `y_i^2`. By (a), `I' := (g_J : J ∈ 𝒥) + (y_1^2, …, y_{n'}^2) ⊆ gr(I)`. Therefore, using (b) and (iii),

`dim_F C/V = dim_F S/I' ≥ dim_F S/gr(I) = dim_F S/I = 2^{n'} − |Σ|`.

**(v) Conclusion.** `dim_F C = 2^{n'}`, so `dim_F V = 2^{n'} − dim_F C/V ≤ |Σ| ≤ binomial(2k+2, k+1)`. ∎

## Checks

- `k = 0`: `V = C`, `dim V = 2 = binomial(2, 1)`.
- `k = 1`, `F = F_3`: `dim V = 6 = binomial(4, 2)` (the three generators `y_3 − y_2`, `y_3 − y_1`, `y_2 − y_1` span `2` dimensions in degree `1`, `3` in degree `2`, `1` in degree `3`).
- The hypothesis `char F ≠ 2` is used only in (i) and (iii) (`1 ≠ −1`).
