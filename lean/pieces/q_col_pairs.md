## Setting

Fix `c ∈ μ^d` (extended by `c_0`), a set `ℛ` of representatives, and `ζ ∈ ℛ`. Then `ζ ∈ μ`, `ζ ≠ 1` and `ζ^{−1} ≠ ζ` (if `ζ^{−1} = ζ`, the defining property of `ℛ`, «exactly one of `ζ, ζ^{−1}` lies in `ℛ`», fails for `ζ`). Put

`A := 𝒞_ζ`,   `B := 𝒞_{ζ^{−1}}`,   `A^* := A ∖ {0}`,   `B^* := B ∖ {0}`,   `α := |A^*|`,   `β := |B^*|`.

`A` and `B` are disjoint, and `W_ζ = A^* ⊔ B^*`. For `s ∈ W_ζ` the point of the box ring is `c_s = ζ` if `s ∈ A^*` and `c_s = ζ^{−1}` if `s ∈ B^*`; in particular `c_s ≠ 1` and `c_s ≠ 0`.

In `B(W_ζ)` put, for `i ∈ A^*` and `l ∈ B^*`,

`x_i := ζ^{−1} t_i − 1`,   `z_l := (ζ t_l)^{−1} − 1`.

(`t_l` is a unit of `B(W_ζ)`: it is the non-zero constant `c_l` plus the nilpotent `t_l − c_l`.)

**Enumerations.** Fix bijections `e_A : [α] → A^*` and `e_B : [β] → B^*` (any bijections: the ideals `I^{bal}_a`, `I^{ph}_a` are invariant under permuting the `x`-variables and, separately, the `z`-variables, since their generating sets are).

## Lemma 6.7

**(i) (the ring)** There is an `F`-algebra isomorphism `Φ : R_{α,β} → B(W_ζ)` with `Φ(x_i) = x_{e_A(i)}` and `Φ(z_l) = z_{e_B(l)}`. Likewise there is an `F`-algebra isomorphism `Φ' : R_{β,α} → B(W_ζ)` with `Φ'(x_l) = z_{e_B(l)}` and `Φ'(z_i) = x_{e_A(i)}` (the names exchanged).

**(ii) (the pair factor)** For `i ∈ A^*` and `l ∈ B^*`, `t_i t_l − 1 = u·(x_i − z_l)` in `B(W_ζ)` with `u = (1 + z_l)^{−1}` a unit. Also `t_s − 1` is a unit for every `s ∈ W_ζ`.

**(iii) (identification)**
- If `0 ∉ A ∪ B` and `α = β =: a`, then `Φ(I^{bal}_a) = I_{c,ζ}` (as ideals of `B(W_ζ)`, `Φ(I)` meaning the image ideal).
- If `0 ∈ B` and `α = β + 1`, then `Φ(I^{ph}_β) = I_{c,ζ}`.
- If `0 ∈ A` and `β = α + 1`, then `Φ'(I^{ph}_α) = I_{c,ζ}`.
- If `|A| ≠ |B|`, then `I_{c,ζ} = 0`.

(These cases are exhaustive: `|A| = α + [0 ∈ A]`, `|B| = β + [0 ∈ B]`, and `0` lies in at most one of `A`, `B`.)

**(iv) (dimensions)** In the three cases of (iii), `dim_F I_{c,ζ}` equals `dim_F I^{bal}_a`, `dim_F I^{ph}_β`, `dim_F I^{ph}_α` respectively; if `|A| ≠ |B|` it is `0`.

**(v) (binomials)** If `F` has characteristic `p` and `q = p^v`, then `binom(q − 1, t) ≠ 0` in `F` for every `0 ≤ t ≤ q − 1`.

**(vi) (the bound)** Suppose moreover `p ≠ 2` (so `q` is odd and `q ≥ 3`), and `|A| = |B|`. Put `N_ζ(c) := N_{bal}(α, q)` if `0 ∉ A ∪ B`, and `N_ζ(c) := N_{ph}(min(α, β), q)` otherwise. Then `dim_F I_{c,ζ} ≥ N_ζ(c)`.

## Proof

(i) `B(W_ζ) = ⊗_{s ∈ W_ζ} F[t_s]/((t_s − c_s)^q)`. For `i ∈ A^*`: `x_i = ζ^{−1}(t_i − ζ)` is a unit multiple of `t_i − c_i`, so `x_i^q = 0`, and `t_i = ζ(1 + x_i)`. For `l ∈ B^*`: `ε_l := ζ t_l − 1 = ζ(t_l − ζ^{−1})` is a unit multiple of `t_l − c_l`, so `ε_l^q = 0`; and `z_l = (1 + ε_l)^{−1} − 1 = −ε_l(1 + ε_l)^{−1}` is a unit multiple of `ε_l`, so `z_l^q = 0`; conversely `t_l = ζ^{−1}(1 + z_l)^{−1}`. So the map `Φ` is well defined (the relations `x_i^q`, `z_l^q` hold) and has an inverse, the map `B(W_ζ) → R_{α,β}` given by `t_{e_A(i)} ↦ ζ(1 + x_i)` and `t_{e_B(l)} ↦ ζ^{−1}(1 + z_l)^{−1}` (well defined: `(ζ(1 + x_i) − ζ)^q = ζ^q x_i^q = 0`, and `ζ^{−1}(1 + z_l)^{−1} − ζ^{−1} = −ζ^{−1} z_l (1 + z_l)^{−1}`, whose `q`-th power is `0`); the two composites fix the generators. For `Φ'` exchange the roles.

(ii) With `t_i = ζ(1 + x_i)` and `t_l = ζ^{−1}(1 + z_l)^{−1}`: `t_i t_l − 1 = (1 + x_i)(1 + z_l)^{−1} − 1 = (x_i − z_l)(1 + z_l)^{−1}`. And `t_s − 1 = (c_s − 1) + (t_s − c_s)` with `c_s ≠ 1`: a non-zero constant plus a nilpotent.

(iii) `I_{c,ζ}` is generated by the `g_σ`, over the bijections `σ : A → B`. If `|A| ≠ |B|` there is none, and `I_{c,ζ} = (∅) = 0`. Otherwise `g_σ = Π_{a ∈ A} f_{min(a,σa), max(a,σa)}`, and each factor is:
- for a pair `{0, s}` (`s ∈ W_ζ`): `f_{0,s} = t_s − 1`, a unit by (ii);
- for a pair `{i, l}` with `i ∈ A^*`, `l ∈ B^*`: `f = (t_b − 1)(t_i t_l − 1)^{q−1}` with `b = max(i, l)`, which is `(unit)·(x_i − z_l)^{q−1}` by (ii).
So `g_σ = (unit)·Π (x_i − z_l)^{q−1}`, the product over the pairs `{i, σ(i)}` avoiding `0`. Multiplying generators by units does not change the ideal (Lemma 6.4 (v)). Now:
- `0 ∉ A ∪ B`: the bijections `A → B` are `σ = e_B ∘ τ ∘ e_A^{−1}` with `τ` a permutation of `[a]`, and the product is `Φ(Π_{i} (x_i − z_{τ(i)})^{q−1})`, a generator of `Φ(I^{bal}_a)`; every generator arises. (The image of an ideal generated by a set is generated by the image of the set.)
- `0 ∈ B`: a bijection `σ : A → B` sends exactly one `i_0 ∈ A = A^*` to `0`; the remaining pairs form a bijection `A^* ∖ {i_0} → B^*`, and the product over them is `Φ` of a generator of `I^{ph}_β`; every pair `(i_0, bijection)` arises from exactly one `σ`.
- `0 ∈ A`: the same with the roles of `A` and `B` exchanged; since `q − 1` is even, `(x_i − z_l)^{q−1} = (z_l − x_i)^{q−1}`, so the product is `Φ'` of a generator of `I^{ph}_α`.

(iv) An `F`-algebra isomorphism is an `F`-linear bijection, and it maps an ideal onto its image ideal of the same dimension. With (iii).

(v) In `F[X]`, `(1 + X)^q = 1 + X^q` (Frobenius). Hence `(1 + X)·Σ_{t=0}^{q−1} (−1)^t X^t = 1 + X^q` (as `q` is odd when `p ≠ 2`; for `p = 2`, `−1 = 1` and the same identity holds), and cancelling the non-zero-divisor `1 + X`, `(1 + X)^{q−1} = Σ_{t=0}^{q−1} (−1)^t X^t`. Comparing coefficients, `binom(q − 1, t) = (−1)^t ≠ 0` in `F`.

(vi) By (iv) and Theorem C of `q_bip_induction.md` (its hypotheses: `3 ≤ q`, `q` odd, and `binom(q − 1, t) ≠ 0` for `t ≤ q − 1`, which is (v)): in the first case `dim I_{c,ζ} = dim I^{bal}_α ≥ N_{bal}(α, q)`; in the second `dim I_{c,ζ} = dim I^{ph}_β ≥ N_{ph}(β, q)` with `β = min(α, β)`; in the third `dim I_{c,ζ} = dim I^{ph}_α ≥ N_{ph}(α, q)` with `α = min(α, β)`. ∎

## Checks

- Exact linear algebra over `F_p` (`μ ⊆ F_p^×` the `r`-th roots of unity, `q = p`, `k = 1`), for every colouring when `(p, q, r) = (7, 7, 3)` and random colourings for `(13, 13, 3)` and `(11, 11, 5)`, and every `ζ ∈ ℛ`: `I_{c,ζ}` computed from the `g_σ` inside `R_c`; the images `Φ(I^{bal})`, `Φ(I^{ph})`, `Φ'(I^{ph})` computed with the substitutions `x_i = ζ^{−1}t_i − 1`, `z_l = (ζt_l)^{−1} − 1`; the two ideals are equal (same rank, and the rank of their union is the same), `dim I_{c,ζ}` equals the directly computed `dim I^{bal}_a` or `dim I^{ph}_a` in `R_{α,β}`, and `dim I_{c,ζ} ≥ N_ζ(c)`; and `I_{c,ζ} = 0` when `|A| ≠ |B|`. 61 checks (18 balanced, 13 with `0 ∈ B`, 8 with `0 ∈ A`, 22 with `|A| ≠ |B|`), 0 failures.
- Negative control (the wrong substitution `z_l := ζ t_l − 1`): the ideal equality of (iii) fails in 19 of the 27 non-zero cases for `(7, 7, 3)` and `(13, 13, 3)` (it can only hold when no pair `{i, l}` with both ends in `W_ζ` occurs).
