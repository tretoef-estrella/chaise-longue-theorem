# Every generator of a layer lifts to the right slice

This file uses, unchanged:
- `q_peeling_lemma.md`: the ring `C_m`, the identification `C_m = C_{m−1}[y_1]/(y_1^{q−1})` (the ring `C_{m−1}` has the variables `y_2, …, y_m`), the slices `W_j(V) ⊆ C_{m−1}` of an ideal `V ⊆ C_m`, and parts (i) (`W_j(V)` is an ideal) and (ii) (`W_j(V) ⊆ W_{j+1}(V)`);
- `q_chain_lemma.md`: partitions, `S_t`, weak dominance `≼`, the options `μ − e_j`, `μ + e_j`, `μ ⊔ 1`, `r̄_j`, `r̲_j`, the list `opt_p(μ)` and its parts (a), (b), (c);
- `q_P2_monotone_options.md`: the size `|μ|`;
- `q_P1_fibres.md`: `F_Λ(μ) := #{p ∈ {1, …, 2h} : opt_p(μ) ∈ Λ}`;
- `q_P3_identities.md`: `D`, `Δ`, column lengths `λ'_c`, tight patterns, their products, the ideals `V_Λ(I)`, and parts (i)–(iv) of its Lemma.

## Setting

Let `F` be a field, `q ≥ 3` odd, `h := (q − 1)/2` (so `L := q − 1 = 2h`), and `m ≥ 1`.

**The partitions `Par_n`.** For `n ≥ 0` let `Par_n := {λ : |λ| ≤ n, |λ| ≡ n (mod 2), ℓ(λ) ≤ h}`.

**Down-sets.** A set `Λ ⊆ Par_m` is a *down-set of `Par_m`* if `λ ∈ Par_m`, `λ ≼ μ` and `μ ∈ Λ` imply `λ ∈ Λ`.

**The layers.** For a down-set `Λ` of `Par_m` and `0 ≤ i ≤ q − 2` put

`Λ_i := {μ ∈ Par_{m−1} : F_Λ(μ) > i}`.

**The ideals.** `V_Λ := V_Λ({1, …, m}) ⊆ C_m`. For the layer, `V_{Λ_i} ⊆ C_{m−1}` is the ideal generated by the products of the tight patterns of the elements of `Λ_i` on the index set `{2, …, m}` (the variables of `C_{m−1}`).

## Proposition

For every down-set `Λ` of `Par_m` and every `i ∈ {0, …, q − 2}`:

`V_{Λ_i} ⊆ W_{q−2−i}(V_Λ)`.

## Proof

**Step 0 (the options stay in `Par_m`).** Let `μ ∈ Par_{m−1}`, `ℓ := ℓ(μ) ≤ h`. Every option `opt_p(μ)`, `p = 1, …, L`, lies in `Par_m`: its size is `|μ| ± 1 ≤ m` with the parity of `m`; `μ + e_j` and `μ − e_j` have length `≤ ℓ`; and `μ ⊔ 1` occurs only when `L − 2ℓ > 0`, i.e. `ℓ < h`, so its length `ℓ + 1 ≤ h`. Consequently the proof of part (c) of `q_chain_lemma.md` applies verbatim to a down-set of `Par_m` (it only compares options with each other): the positions `p` with `opt_p(μ) ∈ Λ` are exactly `1, …, Φ` with `Φ := F_Λ(μ)`.

**Step 1 (reduction).** `W_{q−2−i}(V_Λ)` is an ideal of `C_{m−1}`, so it suffices to show that it contains the product `G` of every tight pattern of every `μ ∈ Λ_i` on `{2, …, m}`. Fix such `μ` and `G`, with pairs `P` and blocks `B_c`, and put `Φ := F_Λ(μ) ≥ i + 1 ≥ 1`. Since `W_j(V_Λ) ⊆ W_{j+1}(V_Λ)`, it suffices to show

`G ∈ W_{q−1−Φ}(V_Λ)`,   (∗)

because `q − 1 − Φ ≤ q − 2 − i`. To prove (∗) we exhibit `f ∈ V_Λ` with `deg_{y_1} f ≤ q − 1 − Φ` whose coefficient of `y_1^{q−1−Φ}` is `±G` (then `±G ∈ W_{q−1−Φ}(V_Λ)`, and `W_j` is a subspace). Every `f` below is a sum of `±` tight-pattern products of some `λ ∈ Λ` on `{1, …, m}`, so `f ∈ V_Λ`. We use the layout of the options (removals at `p ≤ ℓ`, `μ ⊔ 1` at `ℓ < p ≤ L − ℓ`, additions `μ + e_{L+1−p}` at `p > L − ℓ`) and Step 0. There are three cases.

**Case (α): `Φ > L − ℓ`.** Put `j_0 := L + 1 − Φ ∈ {1, …, ℓ}`, so `λ := μ + e_{j_0} = opt_Φ(μ) ∈ Λ`. Since `opt_{Φ+1}(μ) = μ + e_{j_0 − 1} ∉ Λ` when `j_0 ≥ 2`, and rows of equal length give equal options, `j_0` is the first row of its length: `μ_{j_0 − 1} > μ_{j_0}` if `j_0 ≥ 2`. Let `c* := μ_{j_0} + 1`. The column `c*` of `μ` has height `j_0 − 1`; let `B := B_{c*}` (`B = ∅` if `c* > μ_1`). Put the index `1` into `B`. This gives a tight pattern of `λ` on `{1, …, m}`: column `c*` of `λ` has height `j_0`, and the number of pairs `(m − |λ|)/2 = ((m − 1) − |μ|)/2` is unchanged. Its product `f` has `y_1` only in `Δ(B ∪ {1})`; since `1 < b` for all `b ∈ B` and `|B| = j_0 − 1 ≤ h − 1 ≤ q − 2`, part (iii) of `q_P3_identities.md` gives `deg_{y_1} f = j_0 − 1` with top coefficient `(−1)^{j_0 − 1} G`. And `j_0 − 1 = L − Φ = q − 1 − Φ`.

**Case (β): `ℓ < Φ ≤ L − ℓ`.** Then `μ ⊔ 1 = opt_Φ(μ) ∈ Λ`, so `ℓ < h`, and since all copies of `μ ⊔ 1` are equal, `Φ ≥ L − ℓ`; hence `Φ = L − ℓ`. Put the index `1` into the block `B_1` (column 1 of `μ`, height `ℓ`). This is a tight pattern of `λ := μ ⊔ 1` on `{1, …, m}` (column 1 of `λ` has height `ℓ + 1`; the number of pairs is unchanged). By part (iii), its product `f` has `deg_{y_1} f = ℓ ≤ h − 1 ≤ q − 2` and top coefficient `(−1)^ℓ G`. And `ℓ = L − Φ = q − 1 − Φ`. (For `μ = ∅` the block is `{1}`, `Δ = 1`, the degree is `0`, and `Φ = L`.)

**Case (γ): `1 ≤ Φ ≤ ℓ`.** Put `r := Φ`, so `λ := μ − e_r = opt_r(μ) ∈ Λ` and `opt_{r+1}(μ) ∉ Λ`. Since rows of equal length give equal options, `r` is the last row of its length (`μ_{r+1} < μ_r`, with `μ_{ℓ+1} = 0`). Hence column `c := μ_r` of `μ` has height `r`; call its block `S`, `|S| = r`, and write `G = Δ(S)·G'`, where `G'` is the product of the other factors (it involves no index of `S ∪ {1}`). For `b ∈ S`, the pairs `P ∪ {{1, b}}` together with the blocks `B_{c'}` (`c' ≠ c`) and `S ∖ {b}` in column `c` form a tight pattern of `λ` on `{1, …, m}`: column `c` of `λ` has height `r − 1`, the other columns are unchanged, and the number of pairs `(m − |λ|)/2 = ((m − 1) − |μ|)/2 + 1` has grown by one. (If `c = μ_1 = 1` and `r = 1`, then `λ` has one column fewer; the block `S ∖ {b} = ∅` contributes `Δ(∅) = 1`.) Its product is `Δ(S ∖ {b})·D(y_1, y_b)·G'` (`1 < b`). Hence, with `ε_b` as in part (ii) of `q_P3_identities.md`,

`f := Σ_{b ∈ S} ε_b Δ(S ∖ {b}) D(y_1, y_b) G' ∈ V_Λ`.

Only `D(y_1, y_b)` involves `y_1`, with `y_1`-degree `≤ q − 2`. By parts (i) and (ii),

`[y_1^{q−2−t}] f = (−1)^{t+1} (Σ_{b∈S} ε_b Δ(S ∖ {b}) y_b^t) G'`, for `0 ≤ t ≤ q − 2`,

which is `0` for `t ≤ r − 2` and `(−1)^r Δ(S) G' = (−1)^r G` for `t = r − 1`. So `deg_{y_1} f ≤ q − 1 − r` and the coefficient of `y_1^{q−1−r}` is `±G`. And `q − 1 − r = q − 1 − Φ`.

The three cases cover `1 ≤ Φ ≤ L` and are mutually exclusive, which proves (∗). ∎

## Checks

- Verified by exact linear algebra over `F_101` for every nonempty down-set `Λ` of `Par_m` and every `i`, for `(q, m) ∈ {3} × {1..5} ∪ {5} × {1..4} ∪ {7} × {1..3}`: 106 inclusions, 0 failures.
- Negative control: replacing `W_{q−2−i}` by `W_{q−3−i}` gives 47 failures in the same range, so the slice index is sharp.
