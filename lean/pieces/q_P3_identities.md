# Tight patterns and three polynomial identities

This file uses the **Setting** of `q_peeling_lemma.md` (the ring `C_m`) and of `q_chain_lemma.md` (partitions, their rows `μ_i`, length `ℓ(μ)`, size `|μ|`), and `q_P2_monotone_options.md` for `|μ|`.

## Setting

Let `F` be a field, `q ≥ 3` an odd integer, `m ≥ 0`, and

`C_m := F[y_1, …, y_m]/(y_1^{q−1}, …, y_m^{q−1})`.

**Divided difference.** For indices `a ≠ b` put

`D(y_a, y_b) := Σ_{i=0}^{q−2} (−1)^i y_a^i y_b^{q−2−i}`.

(This is the polynomial `(y_b^{q−1} − y_a^{q−1})/(y_a + y_b)`: indeed `(y_a + y_b)·D(y_a, y_b) = y_b^{q−1} − y_a^{q−1}`, using that `q − 1` is even. It is antisymmetric: `D(y_b, y_a) = −D(y_a, y_b)`, because `q − 2` is odd.)

**Vandermonde.** For a finite set of indices `B = {b_1 < ⋯ < b_r}` put

`Δ(B) := Π_{1 ≤ c < c' ≤ r} (y_{b_{c'}} − y_{b_c})`,

with `Δ(∅) = Δ({b}) = 1`. Equivalently `Δ(B) = det(y_{b_c}^{e−1})_{e,c = 1..r}`.

**Column lengths.** For a partition `λ` let `λ'_c := #{i : λ_i ≥ c}` for `c = 1, …, λ_1` (the lengths of the columns of its Young diagram). Then `Σ_c λ'_c = |λ|`.

**Tight patterns.** Let `λ` be a partition and `I` a finite set of indices with `|I| ≥ |λ|` and `|I| − |λ|` even. A **tight pattern of `λ` on `I`** consists of

- a set `P` of `p := (|I| − |λ|)/2` pairwise disjoint 2-element subsets of `I` (the *pairs*), and
- pairwise disjoint subsets `B_1, …, B_{λ_1}` of `I` (the *blocks*) with `|B_c| = λ'_c`,

such that the pairs and the blocks together partition `I`. Its **product** is

`G := Π_{{a<b} ∈ P} D(y_a, y_b) · Π_{c=1}^{λ_1} Δ(B_c)`   (an element of `C_m` when `I ⊆ {1, …, m}`).

**The ideals `V_Λ`.** For a set `Λ` of partitions and a finite index set `I ⊆ {1, …, m}`, let `V_Λ(I) ⊆ C_m` be the ideal generated by the products of all tight patterns on `I` of all `λ ∈ Λ`. Write `V_Λ := V_Λ({1, …, m})`. (If `I = ∅` and `∅ ∈ Λ`, the empty tight pattern has product `1`.)

## Lemma (three identities)

All three are identities between polynomials with integer coefficients, so they hold in `C_m` over every field.

**(i)** For `a ≠ b` and `0 ≤ t ≤ q − 2`, the coefficient of `y_a^{q−2−t}` in `D(y_a, y_b)` (as a polynomial in `y_a`) is `(−1)^{t+1} y_b^t`.

**(ii)** Let `S = {b_1 < ⋯ < b_r}` with `r ≥ 1`, and put `ε_{b_c} := (−1)^{r+c}`. Then

`Σ_{b ∈ S} ε_b · Δ(S ∖ {b}) · y_b^t = 0` for `0 ≤ t ≤ r − 2`, and `= Δ(S)` for `t = r − 1`.

**(iii)** Let `B` be a finite set of indices with `a ∉ B` and `a < b` for all `b ∈ B`. Then

`Δ(B ∪ {a}) = Π_{c ∈ B} (y_c − y_a) · Δ(B)`.

Consequently, if `|B| ≤ q − 2`, then in `C_m` (with `a, B ⊆ {1, …, m}`), `Δ(B ∪ {a})` has degree exactly `|B|` in `y_a`, and its coefficient of `y_a^{|B|}` is `(−1)^{|B|} Δ(B)`. (Here, for `f ∈ C_m`, the degree and coefficients in `y_a` are those of the unique representative in which every exponent of `y_a` is at most `q − 2`, as in `q_peeling_lemma.md`.)

**(iv) (relabelling)** For a permutation `σ` of `{1, …, m}`, acting on `C_m` by `y_i ↦ y_{σ(i)}`, the image of a tight-pattern product of `λ` on `I` is `±` a tight-pattern product of `λ` on `σ(I)`. Hence `σ(V_Λ(I)) = V_Λ(σ(I))`.

## Proof

(i) The term of `D(y_a, y_b)` with `y_a^{q−2−t}` is `(−1)^{q−2−t} y_a^{q−2−t} y_b^t`, and `(−1)^{q−2−t} = (−1)^{t+1}` because `q − 2` is odd.

(ii) The left side is the expansion, along its last row, of the determinant of the `r × r` matrix whose rows are `(y_{b_c}^{e−1})_c` for `e = 1, …, r − 1` and `(y_{b_c}^t)_c` as the last row. (The cofactor of the entry in column `c` of the last row is `(−1)^{r+c}` times the Vandermonde determinant of `S ∖ {b_c}`.) For `t ≤ r − 2` the last row equals one of the others, so the determinant is `0`; for `t = r − 1` the matrix is the Vandermonde matrix of `S`.

(iii) Since `a` is smaller than every element of `B`, the pairs of `B ∪ {a}` are the pairs of `B` together with the pairs `(a, c)`, `c ∈ B`, each contributing `y_c − y_a`. As a polynomial in `y_a`, `Π_{c∈B}(y_c − y_a)` has degree `|B|` with leading coefficient `(−1)^{|B|}`, and `Δ(B)` does not involve `y_a`. If `|B| ≤ q − 2`, no exponent of `y_a` reaches `q − 1`, so nothing is killed in `C_m`.

(iv) `σ` maps pairs to pairs and blocks to blocks of the same sizes. `D(y_{σ a}, y_{σ b}) = ±D(y_{min}, y_{max})` by antisymmetry, and reordering the elements of a block changes `Δ` by the sign of the reordering. ∎

## Checks

- `q = 3`: `D(y_a, y_b) = y_b − y_a`. `q = 5`: `D(y_a, y_b) = y_b^3 − y_a y_b^2 + y_a^2 y_b − y_a^3`.
- (ii) with `r = 2`, `S = {1, 2}`: `ε_1 = −1`, `ε_2 = +1`; `t = 0`: `−1 + 1 = 0`; `t = 1`: `−y_1 + y_2 = Δ(S)`.
- Verified by computer algebra (sympy) for `q ∈ {3, 5, 7, 9}`: (i) for all `t`; `(y_a + y_b)D = y_b^{q−1} − y_a^{q−1}`; (ii) for `r ≤ 5` and all `t ≤ r − 1`; (iii) for `|B| ≤ 4`; 0 failures.
